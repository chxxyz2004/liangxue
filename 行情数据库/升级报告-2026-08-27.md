# 量学系统升级报告

## 完成功能

### 1. 多数据源管理器 (data_source_manager.py)
- 主数据源：腾讯证券（前复权日K + 实时行情）
- 备用数据源：新浪财经
- Fallback机制：主源失效自动切换备用源
- 使用方式：`from data_source_manager import manager; data = manager.get_daily_kline('sz300476', '胜宏科技')`

### 2. 推送通知模块 (notification.py)
- 支持企业微信、飞书、钉钉Webhook推送
- 自动生成日报格式（大盘概况+持仓表现+关键信号）
- 配置方式：设置环境变量 WECHAT_WEBHOOK_URL / FEISHU_WEBHOOK_URL / DINGTALK_WEBHOOK_URL
- 使用方式：`from notification import notif_manager; notif_manager.send_report(report, '量学系统日报')`

### 3. Web工作台基础版 (dashboard_v2.py)
- 端口：8085
- API接口：
  - `/api/overview` - 持仓总览（总市值、成本、盈亏）
  - `/api/holdings` - 持仓明细（价格、涨跌、盈亏、信号）
  - `/api/signals` - 量学信号（倍量柱等）
  - `/api/backtest` - 回测统计（胜率、收益）
- 前端页面：`/workspace/行情数据库/dashboard.html`
- 启动方式：`python3 /workspace/行情数据库/dashboard_v2.py`

### 4. 调研报告 (github开源项目调研报告.md)
- 调研GitHub三大开源项目：
  - daily_stock_analysis (64k stars) - 自动化选股+推送
  - akshare (22k stars) - A股数据爬虫
  - OpenBB (72k stars) - 金融分析平台
- 借鉴要点：
  - 多数据源fallback机制
  - 定时推送通知
  - Provider插件架构思想
- 决定：不直接引用akshare（稳定性差），仅作为备用源

## 使用说明

### 启动Web工作台
```bash
python3 /workspace/行情数据库/dashboard_v2.py
# 访问 http://localhost:8085/dashboard.html
```

### 推送日报到企业微信
```python
from notification import notif_manager
report = notif_manager.generate_daily_report(stocks_data, market_data)
notif_manager.send_report(report, '量学系统日报', channels=['wechat'])
```

### 运行回测
```python
from backtest import run_backtest
result = run_backtest(['sh601138', 'sz300476', 'sh603516'])
print(f"胜率: {result['win_rate']*100:.1f}%")
```

### 对倒检测
```python
from detect_spoofing import detect, pull_5min
bars = pull_5min('sz300476', 60)
signals = detect(bars, '胜宏科技')
print(f"检测到 {len(signals)} 个对倒信号")
```
