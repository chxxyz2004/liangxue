## 三、核心发现

### 3.1 元帅柱为何无信号？

**原因分析**：
- 元帅柱要求回调幅度在 1/3 ~ 1/2 实体之间
- 当前震荡偏弱市场（得分38），`min_drawdown=0.50`阈值放宽至1/2
- 导致元帅柱的判定区间（1/3~1/2）与将军柱（>1/2）部分重叠
- 实际数据中，多数关键柱要么落在黄金柱区间（<1/3），要么直接落入将军柱区间（>1/2）

**结论**：元帅柱在当前市场环境下信号极少，建议与将军柱合并评估。

### 3.2 最佳战法组合

| 排名 | 股票 | 最佳战法 | 胜率 | 均收 | 盈亏比 |
|------|------|---------|------|------|-------|
| 1 | 长电科技 | 黄金柱 | 66.7% | +0.34% | 7.41 |
| 2 | 环旭电子 | 将军柱 | 60.0% | +1.37% | 3.03 |
| 3 | 工业富联 | 将军柱 | 66.7% | -0.20% | 0.52 |
| 4 | 环旭电子 | 倍量柱 | 53.3% | +0.48% | 11.55 |

### 3.3 胜率 vs 盈亏比分析

```
┌──────────────────────────────────────────────────────────────────┐
│  胜率 > 50% + 盈亏比 > 2.0 → 可靠信号，可参与                      │
│  胜率 > 50% + 盈亏比 < 1.0 → 胜率高但单次亏损大，谨慎              │
│  胜率 < 30% + 盈亏比 > 5.0 → 低胜率但大赚，适合小仓尝试            │
│  胜率 < 30% + 盈亏比 < 2.0 → 信号失效，放弃                       │
└──────────────────────────────────────────────────────────────────┘
```

- **长电科技黄金柱**：胜率66.7% + 盈亏比7.41 → 最佳信号
- **环旭电子倍量柱**：胜率53.3% + 盈亏比11.55 → 高盈亏比，适合小仓
- **胜宏科技**：胜率22.2% + 盈亏比9.32 → 低胜率但大赚，适合极小仓试错

### 3.4 市场环境的影响

| 环境得分 | 建议操作 | 原因 |
|---------|---------|------|
| ≥70（强势牛市） | 满仓出击，所有战法有效 | 趋势确认，信号可信度高 |
| 50-69（震荡偏多） | 六成仓，优先黄金柱 | 趋势不明但偏多 |
| 30-49（震荡偏弱） | 四成仓，仅参与胜率>50%的信号 | 需严格筛选 |
| <30（弱势熊市） | 空仓观望 | 系统性风险高 |

**当前环境38分（震荡偏弱）**：应严格执行四成仓限制，且只参与胜率>50%的信号。

## 四、实战建议

### 4.1 信号选择优先级

```
第一优先：长电科技 黄金柱（胜率66.7%，盈亏比7.41）
第二优先：环旭电子 将军柱（胜率60%，均收+1.37%）

第四优先：工业富联 将军柱（胜率66.7%）
```

### 4.2 止损止盈规则

| 情况 | 止损 | 止盈 |
|------|------|------|
| 标准战法 | 关键柱最低价 × 0.98 | 买入价 × 1.15 |
| 环境得分<40 | 买入价 × 0.95（更紧） | 买入价 × 1.10（更低） |
| 环境得分>60 | 买入价 × 0.90（更松） | 买入价 × 1.20（更高） |

### 4.3 仓位控制公式

```
单只仓位 = min(总资金 × 环境系数 × 胜率系数, 总资金 × 20%)

环境系数：≥70分=1.0, 50-69分=0.75, 30-49分=0.5, <30分=0
胜率系数：>60%=1.2, 50-60%=1.0, 40-50%=0.8, <40%=0.5
```

## 五、局限性说明

1. **样本量有限**：640根K线中仅产生88个倍量柱信号，统计显著性不足
2. **市场环境单一**：当前数据主要覆盖震荡偏弱阶段，牛市/熊市数据不足
3. **未考虑板块共振**：未纳入六维框架中的"板块维度"
