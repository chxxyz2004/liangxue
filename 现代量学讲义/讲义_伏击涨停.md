# 第一单元：理论基石

## 第1讲 伏击涨停的奥秘——有规律

### 一、伏击涨停的核心思想

**什么是伏击涨停：**
追击法停是A股市场上追涨停死队通用的手法，但更有前瞻性地伏击涨停，悄悄介入，守候涨停，则是涨停特工队的战法。

**两大前提：**
1. 涨停板是人为的——有人为的炒作，才有股票的涨停
2. 人为的事必然有踪迹——沿着人的踪迹，可以找到他的方法和手段

### 二、四大定律

**第一定律：凡是涨停板，必是人为的**
- 任何一只股票的涨停板都不是天上掉下来的，也不是地里冒出来的
- 涨停板是主力行为的结果
- 研究涨停板就是研究主力的行为

**第二定律：凡是人为的，必然有踪迹**
- 只要是人为的事，必然会留下人的踪迹
- 根据留下的痕迹，一定可以找到他的作案方法和手段
- 这就是"伏击涨停就等于警察抓小偷"的核心思想

**第三定律：凡有踪迹，必然有规律**
- 中国有句古话："无风不起浪"
- 凡是有踪迹的地方，一定有规律可循
- 涨停板的形成有其内在的规律，体现在量柱的变化和量线的交错中

**第四定律：凡有规律，必然可复制**
- 现代科学告诉我们：可以复制的技术，才是科学的技术
- 伏击涨停的方法和技巧，是可以学习和掌握的
- 不是天才才能学会，普通人通过系统学习也能掌握

### 三、从入门到登堂入室

伏击涨停是有层次的，从学习到掌握再到运用，也是有层次的，必须经过从入门到登堂入室、从人道到出神入化的过程。这是复杂的由量进到突变的过程。

五个层次：
1. **有人**——能抓一个涨停板
2. **有术**——能抓两个涨停板
3. **有艺**——能抓三个涨停板
4. **有道**——能抓四个涨停板
5. **有化**——能抓五个涨停板

不同层次，决定不同的境界。不同的层次之间，还有过渡与回归。我们要给自己定位，确认自己目前所处的层次，向自己的眼光和战法升级，向着高手的境界迈进。

## 第2讲 伏击涨停的诀窍——跟着规律走

### 一、换种眼光看，换个手法做

传统技术从均线、K线组合、MACD、KDJ等指标来看，涨停板的介入机会非常少，且难以发现，伏击效果几乎为零。因为所有的传统技术指标天生就不是用来伏击涨停的。

但如果换一种眼光来看，只看最原始的、赤裸裸的量柱和价柱，从量柱和价柱的组合对比中，就能发现许多过去从未发现过的股市规律，还能发现许多过去从未发现过的涨停基因和伏击机会。

### 二、跟着强者走，勤奋出高手

"跟着强者走"有两层含义：
1. 在学习上的强者——比你高一个层次的人
2. 在实战中的强者——已经成功伏击涨停的人

"勤奋出高手"的含义：
- 前面有人能够伏击涨停，你就能伏击涨停
- 关键是要善于总结，从自身找原因
- 将前面已经成功的人当作一面镜子，经常照一照，找出自己的不足之处

有一个方法：你在最后一位，也可以不断进步，成为前一名。每次考试的目标就是超过前面的一个同学，就像朱成从北京大学到哈佛大学的故事一样。

### 三、跟着规律走，实践出高手

现代科学认为，世间万物是有规律的，炒股就一定有科学，涨停板当更有科学。关键在于发现科学、发现规律、运用规律。

**实践案例：** 巴安水务2012年5月至7月，48个交易日内11个涨停板，累计涨幅高达300%。四预报四成功，每次都是"提前介入，守候涨停"。

规律总结：
1. 看基柱：A、B、C三根量柱是当前的低量柱，其次日或隔一日出现涨停板
2. 看价柱：E和H两处价柱的组合形态，是"侯阴加长腿，下跌已到位"
3. 看量线：左侧的实线是预报时画的，实线的原理是遵循规律

## 第3讲 伏击涨停的基础——攻防十字经

### 一、最基本的"两种柱"

伏击涨停的基础是"量柱"和"价柱"。

**量柱：**
走势软件下方的红绿相间的柱体，表示成交量。

**价柱：**
量柱上方的价位柱，也就是人们常说的蜡烛图或K线。

**量柱和价柱是一对血肉相连的兄弟**，丢弃任何一个是错误的。正确的方法是将二者联合起来，一看到"价柱"就联系到它所对应的"量柱"，同样，一看到"量柱"就联系到它所对应的"价柱"。这叫"立体看盘法"，量价合一，见一即二。

### 二、最核心的"十二字令"

> **阳胜进，阴胜出；小倍阳，大胆入。**

**第一层：从量柱上看**
- 红柱高过是阳胜，阳胜则进
- 绿柱高过是阴胜，阴胜就出
- "胜"是"胜利的胜"，不是"花费的胜"

**第二层：从价柱上看**
- 只要今天红柱的实体高于昨天阴柱的实体，就是"阳胜"
- 只要今天绿柱的实体低于昨天红柱的实体，就是"阴胜"
- 价柱的胜一定要看实体，量柱的"实体实底"是胜的临界点

**第三层：从组合上看**
- "量价同胜"是"胜"的重要标志
- 今天的量柱和价柱同时高于昨天的量柱和价柱，即"双向胜"才是"阳胜"
- 反之，如果今天的量柱和价柱同时"双向胜阳"，才是"阴胜"

**第四层：从量价比看**
- "阳胜"或"阴胜"特指"双向胜"
- 如果遇到"单向胜"的状况，最好还是"看一样"，即观望
- 发现"长阴短柱"或"长阳短柱"要具体情况具体分析

**第五层：从倍量上看**
- 只要今天的量柱比昨天的量柱高出一倍左右（不是高出许多），阳柱就是"小倍阳"，阴柱就是"小倍阴"
- 若高出一倍以上，就是"大倍阳"或"倍阳"
- 若高出五倍以上，那就是"五倍阳"或"七倍阳"

### 三、最精彩的"临界点"

**什么是临界点：**
量柱的"实体实底"是胜的临界点，也是我们"进出攻防"的略界点。

**如何判断临界点：**
- 阳胜的临界点：今天红柱的实体高于昨天阴柱的实体
- 阴胜的临界点：今天绿柱的实体低于昨天红柱的实体
- 量柱的"胜"看高度，价柱的"胜"看实体

### 四、最狡猾的"阴阳柱"

**什么是阴阳柱：**
在走势图上有些量柱看起来是"阴的"，实质上是"阳的"，如高开低走的阴柱就是假阴；有时看起来是"阳的"，实质上是"阴的"，即低开高走的阳柱就是假阳。

**特别警惕：**
特别是"临界点"附近出现的这种"阴阳柱"，往往是骗人的重要量价柱。

**实战要点：**
- 假阴真阳往往是主力吸筹的信号
- 假阳真阴往往是主力出货的信号
- 要结合后续走势验证

## 第4讲 伏击涨停的工具——量柱七因子

### 一、量柱七因子的定义

**口诀：**
> 向左看，就近比，识别量柱很容易。

**七因子定义：**
| 因子 | 定义 | 特征 |
|------|------|------|
| 高量柱 | 某一阶段最高量柱 | 欲望与走向的温度计；通常表示下跌，反常情况读错 |
| 低量柱 | 某一阶段最低量柱 | 底线与底式的温度计；通常表示上涨，反常情况读错 |
| 平量柱 | 与左侧量柱高度基本相等 | 蓄势与爆发的温度计；通常示大涨，反常情况小涨 |
| 倍量柱 | 比左侧量柱高出一倍左右 | 实力与巧动的温度计；通常示大涨，反常情况小涨回调 |
| 梯量柱 | 比左侧量柱逐步升高 | 强攻与强退的温度计；通常逐步走强，反常情况逐步走弱 |
| 缩量柱 | 比左侧量柱逐步降低 | 价位与人气温度计；通常逐步走低，反常情况逐步增高 |
| 黄金柱 | 七种量柱的升级版 | 牛气与黑马温度计；通常逐步走高，反常情况逐步走弱 |

### 二、量柱七因子的组合

**成对关系：**
- 高量柱 ↔ 低量柱
- 平量柱 ↔ 倍量柱
- 梯量柱 ↔ 缩量柱

**黄金柱的本质：**
黄金柱是上述六种量柱的升级，它仿佛是音乐符号中的"延音符"，可以加到任何符号上，让任何一种量柱都可以升华为"黄金柱"。

### 三、量柱七因子的实战意义

一定的因子可以组合成丰富多彩的涨停基因；一定的涨停基因按一定的规律排列组合，又可组成丰富多彩的涨停密码。

## 第5讲 伏击涨停的法宝——股市三规律

### 一、量柱的三大特性

1. **原生性**：量柱是走势图表下方那参差不齐、红绿相间的柱状体。它是每时每刻实际成交量的真实记录，它是未经人工修改的、实实在在的量价结合体。

2. **真实性**：量柱就是用真金白银堆起来的，想作假也必须用大量的真金白银才能奏效，一般情况下得不偿失，因此庄家和主力很少对量柱动手脚。

3. **全息性**：量柱是买卖双方在某一时段、某一价位殊死拼杀后的即时平衡柱，是供求双方对立统一的量价平衡体。它记录了全部信息，蕴藏着全部奥妙，必然蕴含着涨停起伏的全部规律。

### 二、神奇的操盘密钥

**操盘密钥：** 比"十二字令"更巧妙的买卖信号。

**核心法则：**
- 凡是倍量柱后面三天出现价升量缩，就是黄金柱
- 黄金柱是主力的成本线，跌破意味着主力放弃
- 守住黄金柱意味着行情延续

### 三、三先规律

**三先规律：**
1. **卖在买先**——卖买平衡律：任何一只股票，从它产生的那一天起就具备了"卖在买先"的特性天分。首先必须有人卖出，才会有人买进。
2. **价在量先**——价量平衡律：量是价的基础，价是量的表现。
3. **庄在散先**——庄家导向律：主力总是在化巧巧，他们玩弄散户，他们有成功也有失败。

### 四、三先规律的运用

用"三先规律"来检验庄家、衡量主力，一根量柱就能看出主力的意图和动向。弄懂这三个规律，再来看股票的运行，就会像赵本山的小品一样轻松随意。

## 第6讲 伏击涨停的眼光——股市探宝仪

### 一、眼光的"透视性"

**核心观点：** 眼光是所有行为的起点，也是伏击涨停的起点。不同的眼光决定伏击涨停的成功与失败。

**透视性含义：** 透过量柱的表象，看到主力的本质意图。不是看K线的颜色，而是看量柱背后的力量对比。

**案例：** 索罗斯在人们疯抢黄金时加速清仓，国际金价大跌30年最大单日跌幅，他纯赚10亿美元。

### 二、眼光的"折射性"

**核心观点：** 同样的量柱，在不同位置、不同背景下，有不同的含义。需要通过多角度分析来验证。

**案例：** 某股票连续两个跳空下影，非常吓人，但其低点刚好与F柱的实底持平，量柱逐渐缩小，这是"双弧度空，缩量洗盘"形态，后面往往有中到大阳出现。

### 三、眼光的"双向性"

**核心观点：** 同样的股票，有人看多，有人看空，这就是眼光的双向性。

**案例：** 某股票在风险环生的次日却涨停了。原因是在A、B两个涨停板之间是"缩量洗阴洗盘"，B、C之间是一连串"长阴短柱洗盘"，C柱前后是"倍量伸缩异动"。

### 四、眼光的"继承性"

**核心观点：** 你只有继承了优秀的案例、优秀的方法，你的眼光才会比别人超前。

**教训：** 有些人用惯了传统技术，量学理论再好也不接受；有的人对自己手中的股票有一种天生的情圣，即使它走坏了，他还幻想着它会走好。

### 五、眼光的"自闭性"

**三种表现形式：**
1. **思维盲点**：自己用熟了的东西，总以为是最好的
2. **感觉盲点**：只看图形而忽视制造图形后面的人
3. **时间盲点**：盯着他股而错过正在涨停的股票

## 第7讲 伏击涨停的眼力——股市探宝机

### 一、静态分析法

**核心方法：** 用"左推法就近比较"，提取的各种形态才好辨认。

**分析步骤：**
1. 找出重要量柱：A是倍量柱，B是高量柱，D是低量柱，E是平量柱
2. 观察量柱的排列组合
3. 判断量柱的性质和级别

### 二、动态分析法

**核心方法：** 活力就是动力，动力暗示动向，动向必有动静。

**分析方法：**
1. 观察量柱的动态变化
2. 分析价量关系的演变
3. 判断主力的动向和意图

### 三、规律分析法

**核心方法：** 用规律来分析量柱，可以更准确地判断走势。

**案例分析：**
某股票从630元到29.25元，累计涨幅达346.71%。最重要的变态柱是"高量柱"。连续三个常态高量柱后上涨，是一种操盘规律。抓住第四个高量柱出现后上涨，符合巧合。

# 第二单元：核心战法

## 第8讲 王牌——涨停起搏器

### 一、将军柱的三个标准

**第一个标准：看量柱**
将军柱是独当一面的柱子，必须是一柱定音。

**第二个标准：看价柱**
基柱后三日的收盘价不低于基柱的开盘价。不破实底就是：基柱后三日的收盘价没有跌到基柱的开盘价。

**第三个标准：看量柱群**
基柱后三日的量柱都不超过基柱。

**三种情况：**
- 第一种情况：基柱后三日量柱可以参差不齐，但最后一根量柱低于基柱中部
- 第二种情况：基柱后三日量柱逐步缩小，形成"量柱群"
- 第三种情况：基柱后三日量柱出现"阶梯状"

### 二、黄金柱的三个标准

**标准一：** 必须是某一阶段的"将军柱"。

**标准二：** 其后三天必须价升量缩。

**标准三：** 三天内不能跌破黄金柱的最低价位。

**黄金柱的特征：**
- 基柱后三日的量柱和价柱明显偏离
- 一呈"价升量缩"状，或者呈"升量背离"状
- 像一个"趴口"，即将张开

### 三、黄金柱的预判技巧

**预判方法：**
- 先找倍量柱
- 再看后三天的量价关系
- 确认价升量缩后，判定为黄金柱
- 黄金柱形成后，在回踩时介入

**口诀：**
> 找"趴口"，看偏离，价升量缩黄金柱。

### 四、研判中的两个原则

**原则一：先者优先**
当多个黄金柱在一起时，以最先形成的为准。

**原则二：空补空**
如果有多个黄金柱，后面的黄金柱可以补充前面的不足。

### 五、元帅柱的三个标准

**核心特征：**
隐藏在标准黄金柱左侧的不显眼的基准黄金柱，称之为"隐形黄金柱"。凡是有"隐形黄金柱"的，后面的走势往往更加强劲。

**判定标准：**
- 符合"先者优先"的原则，基柱在另一柱左侧，先者在先
- 向上跳空形成的将军柱或黄金柱，依次替空化向左移几次
- 从基础黄金柱开始，后面的走势步步高升

## 第9讲 跳板——金线战法要点

### 一、金线战法的画线（顺势画线）

**什么是金线：**
所谓"金线"，就是"黄金线"的简称，它是主庄苦心经营的"攻防线"，又是主庄步步为营的"生命线"。离开了这条线，主庄不可能调动他的千军万马，也不可能协调他的资金运作。所以，如果抓住了他的黄金线，就等于抓住了主庄的攻防棋线眼。

**黄金线的取点方法：**
1. 以黄金柱自身的实顶或实底画线
2. 以黄金柱后三日的最低实底画线
3. 以黄金柱后三日最低的虚底画线

**取点和画线原则：**
> 先找实，后找虚，微调抓战机。

**实战案例：** 浙报传媒2013.6.14日
- A柱：取基柱的实顶，B柱取基柱后三日的最低点，这两条线画出后，仿佛有了两个跳板
- C柱：取基柱的实顶线，由于后来的行情发生了变化，向下击穿了实顶黄金线，可在C柱的实底上画出第二条黄金线
- D柱：取基柱后三日的实底，后来行情发生了变化，再取D柱自身的实底

### 二、对付强庄的画法（强庄踩顶）

**核心战法：**
对付强庄的"金线战法"，就是以黄金柱所对应的价柱实顶画出金线，用测算涨幅来确认主力的攻防路线。

**实战要点：**
- 强庄股的黄金线往往比较明显
- 主力会依托黄金线进行拉升
- 回踩黄金线是最佳介入点
- 强庄股案例：西藏发展、超华科技、川投股份

**特点：**
- 多条金线层递有力，完成了量柱互换
- 一旦突破金线，就要迅速跃起
- 走势显得错落有致，大气磅礴

### 三、对付精庄的画法（精庄踩脚）

**核心战法：**
对付精庄的"金线战法"，就是以黄金柱（或将军柱）后一日价柱的最低实底和虚底画出虚实两条金线，用测算或确认主庄的攻防路线，进而规划出我们介入或退出的路径。

**实战要点：**
- 虚实双线看起来比"强庄股的金线"简单，但其实战效果前瞻性非常强
- 在虚实相间的两条金线之间可设立伏击圈
- 选择虚线介入或实线介入
- 本例中采用虚线介入法

**双轨战法：**
主力往往用实线保护自己，用虚线打击对手，这是"以实击虚，以虚掩实"。不习舞相的对手，往往会在主力的"虚线攻击"下乖乖交出筹码。

### 四、对付狡庄的画法（狡庄踩脚）

**核心战法：**
对付狡庄的"金线战法"，是根据实际情况对金线予以调整。这种调整，不能靠猜，而要顺势而为，从主力走过的脚印上，找到更加科学完美的伏击路线。

**核心原则：**
> 任何有效的金线都不是我们画出来的，是主力用行动画出来的。
> 想对付狡庄，必须比狡庄更狡猾。

**狡庄特点：**
- 不按常理出牌
- 不时击穿自己的黄金线
- "上一棒头，下一棒子"

**调整方法：**
- A中找A，实中找虚
- 上下虚实相生
- 利用主力行为轨迹找黄金线

## 第10讲 核心——金线战法部曲

### 一、金线战法的核心：找准黄金柱

**找柱要点：**
1. 先找倍量柱
2. 再看后三天是否价升量缩
3. 确认黄金柱的位置和性质
4. 找准黄金柱是金线战法的第一步

### 二、金线战法的核心：跟着主力走

**核心思想：**
- 主力的动作是有规律的
- 通过金线可以追踪主力的行踪
- 跟随主力，而不是对抗主力

### 三、金线战法的灵魂：用活黄金柱

**灵活运用：**
- 黄金柱的质量和位置决定战法的成功率
- 要区分真假黄金柱
- 要理解黄金柱背后的主力意图

## 第11讲 骨架——"黄金双线"画法

### 一、"黄金双线"的基本原理

**什么是黄金双线：**
在同一根黄金柱上，画出两条黄金线：一条以实顶为基准，一条以实底为基准。两条线形成"双线"结构。

**核心意义：**
- 实顶线是进攻线
- 实底线是防守线
- 双线之间是主力的成本区

### 二、"黄金双线"的买卖决策

**买入信号：**
- 股价回踩实底线企稳
- 倍量柱确认支撑有效
- 量价配合良好

**卖出信号：**
- 股价跌破实底线
- 量柱异常放大
- 主力出货迹象

### 三、"黄金双线"的灵活应用

**实战要点：**
- 双线结构越清晰，信号越可靠
- 要结合其他量柱形态综合判断
- 注意双线的角度和长度

---

## 第12讲 抗线——"黄金十字"画法

### 一、什么是"黄金十字"

**定义：**
"黄金十字"是由黄金线和另一条重要量线交叉形成的十字形态。

**形成条件：**
1. 一条水平黄金线
2. 一条斜向的趋势线
3. 两条线形成交叉

### 二、如何寻找"黄金十字"

**寻找方法：**
1. 找出黄金柱和对应的黄金线
2. 画出趋势线（连接重要高低点）
3. 观察交叉点的位置
4. 交叉点往往是重要的买卖信号

### 三、如何使用"黄金十字"

**使用原则：**
- 交叉点上方的黄金线是压力
- 交叉点下方的黄金线是支撑
- 突破交叉点是买入信号
- 跌破交叉点是卖出信号

### 四、如何纠正"黄金十字"

**纠错要点：**
- 不是所有的交叉都是有效的
- 要验证交叉点后的走势
- 不符合预期的交叉要重新审视

### 五、实战验证"黄金十字"

**验证方法：**
- 用历史案例验证交叉点的有效性
- 统计交叉点后的走势概率
- 在实践中不断提高判断能力

---

## 第13讲 标尺——大阴线线法

### 一、"阴胜战法"的原理

**核心概念：**
"阴胜"是指绿柱高过红柱，意味着空方力量占优。但"阴胜"有真假之分，需要仔细辨别。

**实战意义：**
- 真阴胜是卖出信号
- 假阴胜是买入机会
- 关键在于辨别真假

### 二、"大阴实攻"的画法

**画法要点：**
- 以大阴柱的实底为基准
- 向左画水平线
- 这条线是多头的最后防线

**实战应用：**
- 股价回踩大阴线企稳是买入机会
- 跌破大阴线是止损信号
- 大阴线是重要的支撑位

### 三、"大阴中阳"的画法

**画法要点：**
- 以大阴柱中的阳柱实顶为基准
- 画出支撑线
- 这条线比大阴线更强

**实战应用：**
- 中阳线是大阴中的亮点
- 突破中阳线是强势信号
- 回踩中阳线是介入良机

### 四、"阴胜战法"的要点

**要点总结：**
1. 先辨别阴阳柱的真假
2. 再确定支撑线的位置
3. 最后选择介入时机
4. 设置好止损位

## 第14讲 暗号——阴胜柱战法

### 一、"长阴短柱"的基本玩法

**定义：**
"长阴短柱"是指一根长长的阴线，但对应的量柱却很短。

**市场含义：**
- 股价大跌但量能萎缩
- 说明抛压不重
- 往往是主力洗盘的信号

**实战玩法：**
- 在长阴短柱的次日介入
- 止损位设在长阴的最低点
- 目标位看前一个平台的顶部

### 二、"假阴真阳"的识别技巧

**识别方法：**
- 高开低走的阴柱，实体很小
- 对应的量柱也很短
- 实际上是主力在吸筹

**实战应用：**
- 假阴真阳是买入信号
- 要等次日确认后再介入
- 配合黄金柱使用效果更佳

### 三、经典战法解析

**案例一：**
某股票出现长阴短柱，次日放量上涨，突破长阴的最高点，确认是主力洗盘后的拉升。

**案例二：**
某股票出现假阴真阳，量柱极短，后续连续小阳线推升，形成黄金柱后大涨。

## 第15讲 抓手——一剑封喉战法

### 一、"一剑封喉"的机理

**核心概念：**
"一剑封喉"是指在关键位置出现一根倍量柱，一举突破前期平台，形成涨停或大涨。

**形成条件：**
1. 前期有充分蓄势（平台整理）
2. 出现倍量柱突破
3. 突破后不回踩或回踩不破

### 二、"一剑封喉"的表法

**表法要点：**
- 倍量柱是信号柱
- 突破位是介入点
- 止损位设在倍量柱的最低点

**实战操作：**
- 在倍量柱当天尾盘介入
- 或次日回踩时介入
- 严格止损，不可犹豫

### 三、"一剑封喉"的凹口诀

**凹口诀：**
"凹口淘金"是"一剑封喉"的前置条件。在凹口位置出现倍量柱，是最佳的介入时机。

### 四、"一剑封喉"的满盘诀

**满盘诀：**
当"一剑封喉"形成后，后续往往有一波可观的涨幅。要持有到出现卖出信号为止。

## 第16讲 先兆——倍量伸缩战法

### 一、"倍量伸缩"的基本特征

**定义：**
"倍量伸缩"是指倍量柱和缩量柱交替出现的形态。

**特征：**
- 倍量柱后出现缩量柱
- 缩量柱后再次倍量柱
- 形成"伸缩"节奏

**市场含义：**
- 倍量柱是主力建仓或拉升
- 缩量柱是主力洗盘或蓄势
- 伸缩交替说明主力在控制节奏

### 二、"倍量伸缩"的伏击位置

**伏击点：**
- 倍量柱当天的尾盘
- 缩量柱后的倍量柱形成时
- 回踩黄金线企稳时

### 三、"倍量伸缩"的涨停契机

**契机判断：**
- 倍量柱后缩量三日
- 缩量柱低于倍量柱的一半
- 再次出现倍量柱时是涨停契机

### 四、"倍量伸缩"的启动迹象

**启动信号：**
- 倍量柱突破前期平台
- 量能配合良好
- 价柱稳步推升

### 五、"倍量伸缩"的位量论证

**论证方法：**
- 分析倍量柱的位置（低位还是高位）
- 论证缩量的程度（是否是有效缩量）
- 确认后续倍量柱的力度

## 第17讲 契机——现场直播法

### 一、"现场直播"的基本特征

**核心概念：**
"现场直播"是指在盘中实时观察量柱和价柱的变化，即时做出买卖决策。

**特征：**
- 需要快速反应能力
- 需要对量柱理论有深刻理解
- 需要丰富的实战经验

### 二、"现场直播"的市场机制

**机制解析：**
- 盘中量柱的变化反映主力的即时行为
- 价柱的变化反映市场的即时反应
- 两者结合可以判断当天的走势

### 三、"现场直播"的介入时机

**时机选择：**
- 开盘后30分钟的量柱变化
- 午盘前的关键量柱形成
- 尾盘最后的量柱确认

# 附录：核心公式汇总

## 一、黄金线测幅公式

```
第一目标位 = 黄金柱最低价 × 2
第二目标位 = 黄金柱最低价 × 2.5
实际涨幅 = (目标位 - 介入价) / 介入价 × 100%
```

## 二、金线战法买入公式

```
买入点 = 黄金线回踩企稳 + 倍量柱确认
止损点 = 黄金线下方 3%
目标位 = 前高或测算涨幅
```

## 三、十二字令判定公式

```
阳胜 = 量柱双向胜 + 价柱实体胜
阴胜 = 量柱双向负 + 价柱实体负
小倍阳 = 量柱高出一倍左右 + 价柱上涨
大胆入 = 确认阳胜后介入
```

## 四、黄金柱判定公式

```
黄金柱 = 将军柱 + 后三日价升量缩 + 三日不破实底
```

## 五、金线战法画线公式

```
实顶线 = 黄金柱对应价柱的实顶
实底线 = 黄金柱后三日最低实底
虚底线 = 黄金柱后三日最低虚底
```
