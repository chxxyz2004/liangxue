## 一、什么是四维看盘

四维看盘是量学理论的核心看盘方法，强调从**四个维度**综合分析股票的价格和成交量，遵循**就近对比原则**，通过**量价阴阳变化**预判涨跌趋势。

### 核心定义

- **价柱**：记录每日开盘、最高、最低、收盘价
- **量柱**：记录每日成交量（资金态度的直观体现）
- **阴阳**：阳线（收涨）= 多方胜利；阴线（收跌）= 空方胜利
- **四维**：价格维、成交量维、时间维、空间维

### 市场机理

```
股价 = f(资金, 情绪, 时机)

资金 → 成交量（量柱）
情绪 → 买卖意愿（阴阳变化）
时机 → 时间节点（时间维）
空间 → 支撑压力（空间维）
```

**核心逻辑**：
1. 量在价先：成交量变化通常领先价格变化
2. 量价互证：量与价必须相互验证，单边不可信
3. 阴阳转化：阳中有阴、阴中有阳，辩证看待
4. 平衡失衡：市场永远在平衡与失衡之间循环

## 二、四维循环对比法

四维看盘遵循**就近对比原则**，从当前价柱开始，按以下顺序循环对比：

### 第一维：从右到左（时间回溯）

**目的**：寻找历史参照系

**方法**：
- 从今日K线向左依次对比
- 峰跟峰比量柱：筹码是否转移
- 谷跟谷比价柱：主力是否撤离
- 寻找相似形态和量价特征

**口诀**：
> "往左看，找参照；峰比峰，谷比价；主力习惯藏左边"

### 第二维：从上到下（空间定位）

**目的**：判断当前位置

**方法**：
- 从高点向下扫描，寻找关键价位
- 识别峰顶线、谷底线、黄金线等量线
- 判断当前价格在量线体系中的位置
- 确定支撑位和压力位

**口诀**：
> "从上到下找关键；峰顶线是压力关；谷底线是生命线"

### 第三维：从左到右（趋势演进）

**目的**：观察趋势演变

**方法**：
- 从左向右观察量价配合
- 判断趋势方向（上升、下降、横盘）
- 识别量柱形态变化（倍量、缩量、梯量）
- 观察量价关系健康度

**口诀**：
> "从左到右看趋势；量价配合是根本；背离预警要警惕"

### 第四维：从下到上（反弹动能）

**目的**：评估反弹力度

**方法**：
- 从底部向上观察反弹过程
- 量能是否逐步放大（梯量柱）
- 价格是否突破关键阻力
- 反弹是否得到量价确认

**口诀**：
> "从下到上看反弹；量能放大是真干；无量反弹都是骗"

## 三、量价阴阳辩证法

### 阴阳定义

| 类型 | 定义 | 市场含义 |
|------|------|----------|
| 阳胜 | 量增价涨 | 多方占优，趋势健康 |
| 阴胜 | 量降价跌 | 空方占优，趋势走弱 |
| 阳假 | 量缩价涨 | 上涨乏力，警惕背离 |
| 阴假 | 量增价跌 | 下跌恐慌，可能见底 |

### 四种基本组合

```
         价涨（阳）        价跌（阴）
        ┌───────────────┬───────────────┐
量增（强）│  真阳胜·强势  │  真阴胜·弱势  │
        │  持股/加仓    │  减仓/观望    │
        ├───────────────┼───────────────┤
量缩（弱）│  假阳·虚涨   │  假阴·惜售    │
        │  警惕/观望    │  关注/潜伏    │
        └───────────────┴───────────────┘
```

### 十二字令

> **阳胜进，阴胜出；小倍阳，大胆入**

- **阳胜进**：量价双胜，多方占优，果断进场
- **阴胜出**：量价双败，空方占优，立即离场
- **小倍阳**：量比昨日略增（1.5-2倍），价涨，主力有序建仓
- **大胆入**：小倍阳确认，可放心介入

## 四、三维互动体系

量学核心方法论：**量柱选股 → 量线选价 → 量波选时**

### 第一维：量柱选股（基础）

**功能**：发现涨停基因

**方法**：
- 识别六大元素：高量柱、低量柱、倍量柱、平量柱、梯量柱、缩量柱
- 判定关键柱：黄金柱、元帅柱、将军柱
- 检测异动：量柱异常变化往往是主力动作信号

**输出**：候选股票池

### 第二维：量线选价（核心）

**功能**：精准定价

**方法**：
- 画量线：峰顶线、谷底线、黄金线、元帅线、将军线
- 找精准线：被多次验证的水平支撑/压力位
- 定目标位：量线测算涨幅目标

**输出**：买入价位、目标价位、止损价位

### 第三维：量波选时（临门一脚）

**功能**：盘中决策

**方法**：
- 观察分时量波：波形、波向、波势、波幅
- 十字线定位：平衡线移植到分时图
- 四步攻防：先防守后进攻，先确认后跟随

**输出**：最佳买入时机、盘中战术

## 五、实战操作步骤

### 盘前预案（三步走）

```
第一步：扫图识势（缩图看势）
  - 打开股票，缩图观察整体趋势
  - 判断当前处于什么位置（低位/中位/高位）
  - 识别主要量线（峰顶线、谷底线、黄金线）

第二步：找柱识庄（放图察柱）
  - 放大查看最近30-60根K线
  - 寻找倍量柱、黄金柱、关键量线
  - 分析主力意图（吸筹/拉升/出货）

第三步：定计划（临界预判）
  - 上行找大阴实顶（压力位）
  - 下行找大阳实底（支撑位）
  - 制定买入价、止损价、目标价
```

### 盘中盯盘（四关注）

```
关注一：量波形态
  - 白线（价格）是否在黄线（成本）上方
  - 红波多还是绿波多
  - 是否有"蓄势波""犹豫波"

关注二：量价配合
  - 价格上涨时量能是否放大
  - 价格回调时量能是否萎缩
  - 是否出现量价背离

关注三：十字线反应
  - 价格是否回踩十字线（平衡线）
  - 触及后是否有反向运动
  - 确认支撑/压力有效性

关注四：异动侦测
  - 该涨不涨 → 弱势信号
  - 该跌不跌 → 强势信号
  - 放量突破 → 关注持续性
```

### 盘后复盘（四维循环）

```
第一步：从右到左（时间回溯）
  - 今日K线与历史相似形态对比
  - 量柱形态是否出现新的信号
  - 关键量线是否被有效突破/回踩

第二步：从上到下（空间定位）
  - 当前价格在量线体系中的位置
  - 上方压力位、下方支撑位
  - 盈亏比是否合理

第三步：从左到右（趋势演进）
  - 本周趋势是否延续
  - 量价配合是否健康
  - 是否需要调整操作策略

第四步：从下到上（反弹动能）
  - 反弹是否得到量能确认
  - 突破关键阻力是否有效
  - 下周操作方向
```

## 六、市场机理深度解析

### 量价关系的本质

```
成交量 = 多空分歧程度
  - 放量 = 分歧加大（有人拼命买，有人拼命卖）
  - 缩量 = 意见一致（要么都看好，要么都看空）

价格 = 多空博弈结果
  - 上涨 = 买方力量强
  - 下跌 = 卖方力量强
```

### 主力行为解码

| 量价形态 | 主力意图 | 操作建议 |
|---------|---------|---------|
| 低位倍量柱 | 主力进场吸筹 | 关注，等待确认 |
| 倍量后缩量回踩 | 洗盘，测试支撑 | 黄金线附近介入 |
| 梯量柱逐步放大 | 主力边拉边吸 | 持股待涨 |
| 高位放量滞涨 | 主力出货 | 减仓/离场 |
| 缩量涨停 | 主力高度控盘 | 持股，设止盈 |
| 地量地价 | 底部区域 | 关注，等待启动信号 |

### 平衡与失衡循环

```
        平衡状态
      ↗        ↖
   失衡 ←        → 失衡
   （涨）          （跌）
      ↖        ↗
        平衡状态

规律：
- 平衡 → 失衡：趋势启动
- 失衡 → 平衡：趋势衰竭
- 关键：识别转换点（临界点）
```

## 七、常见误区与纠正

| 误区 | 正确理解 |
|------|---------|
| 只看K线不看量柱 | K线是表象，量柱是本质；量在价先 |
| 放量涨就追，放量跌就跑 | 必须结合位置：低位放量是机会，高位放量是陷阱 |
| 阳线一定好，阴线一定坏 | 假阴真阳可以是机会，假阳真阴必须警惕 |
| 指标金叉就买，死叉就卖 | 传统指标滞后，量学看盘更前瞻 |
| 预测明天涨跌 | 量学不算命，只做概率优势下的决策 |

## 八、总结

四维看盘是量学理论的核心看盘方法，其精髓在于：

1. **四维循环**：从右到左、从上到下、从左到右、从下到上
2. **就近对比**：峰比峰、谷比价，寻找历史参照
3. **量价阴阳**：辩证分析，识别真假信号
4. **三维互动**：量柱选股 + 量线选价 + 量波选时

**终极目标**：找到平衡与失衡的建构区间，预判涨跌趋势，实现"伏击涨停"。

> **记住**：量柱是有价的，价柱是有量的。看不懂量柱，就是当"独眼龙"。
