# 量学信号库

本文件汇总量学核心信号的识别规则、实战案例和失效边界。

## 一、量柱信号详细规则

### 1. 倍量柱
- **定义**：当日成交量 ≥ 前一日成交量×2
- **计算公式**：量比 = 当日成交量 / 前一日成交量，量比 ≥ 2
- **实战意义**：主力主动买入，上涨动能强劲
- **识别规则**：
  1. 量比 ≥ 2（含量比=2）
  2. 收盘价 > 开盘价（阳线）
  3. 涨幅 > 0%（最好>2%）
- **右确认条件**：次日继续上涨或放量突破倍量柱高点
- **失效边界**：高位倍量（涨幅>7%）可能是主力出货，需警惕
- **现代升级**：量化监管后（2026年8月），倍量柱可靠性提升（对倒减少）
- **案例**：富联 2026-08-26 量比3.2，次日继续上涨

### 2. 缩量柱
- **定义**：当日成交量 < 前一日成交量×0.5
- **计算公式**：量比 = 当日成交量 / 前一日成交量，量比 < 0.5
- **实战意义**：抛压减轻，可能止跌
- **识别规则**：
  1. 量比 < 0.5
  2. 价格企稳（跌幅<3%或收阳）
- **右确认条件**：次日放量上涨
- **失效边界**：缩量下跌（量比<0.5且跌幅>5%）不是止跌信号
- **案例**：淳中 2026-08-25 量比0.3，但次日继续下跌（未确认）

### 3. 高量柱
- **定义**：近期（20日）内最高成交量
- **计算公式**：当日成交量 = max(近20日成交量)
- **实战意义**：多空分歧最大，方向待确认
- **识别规则**：
  1. 当日成交量为近20日最高
  2. 需要右确认（次日走势决定方向）
- **右确认条件**：次日不跌破高量柱低点 = 看涨；跌破 = 看跌
- **失效边界**：高位高量柱（股价相对高位）多为出货信号
- **案例**：胜宏 2026-08-27 盘中高量，但收盘回落

### 4. 低量柱
- **定义**：近期（20日）内最低成交量
- **计算公式**：当日成交量 = min(近20日成交量)
- **实战意义**：抛压枯竭，可能见底
- **识别规则**：
  1. 当日成交量为近20日最低
  2. 价格企稳（跌幅<2%）
- **右确认条件**：次日放量上涨
- **失效边界**：下跌趋势中的低量柱可能是阴跌延续
- **案例**：环旭 2026-08-22 低量柱后反弹3%

### 5. 百日低量柱
- **定义**：100个交易日内最低成交量
- **计算公式**：当日成交量 = min(近100日成交量)
- **实战意义**：长期底部信号，重大转折
- **识别规则**：
  1. 当日成交量为近100日最低
  2. 价格在长期低位（相对底部区域）
- **右确认条件**：后续3-5日不再创新低 + 放量突破
- **失效边界**：需要配合趋势判断，单独使用不可靠
- **案例**：暂无持仓股中出现过百日低量柱

## 二、价线信号详细规则

### 1. 黄金线
- **定义**：以涨停板或大阳线顶部为基准的黄金分割线
- **计算公式**：黄金线 = 涨停板顶部 × 0.5（或量柱顶部 / 2）
- **实战意义**：强势股回调的强支撑位
- **识别规则**：
  1. 前期有涨停板或大阳线（涨幅>7%）
  2. 当前价格接近黄金线位置
- **操作信号**：触及黄金线且缩量 = 买入机会
- **失效边界**：跌破黄金线且放量 = 趋势转弱
- **案例**：淳中黄金线93元（8/24涨停板顶部93×0.5≈46.5，实际用涨停板顶部作为支撑参考）

### 2. 生命线
- **定义**：连接波段高点的压力线
- **计算公式**：连接近3-5个波段高点形成的趋势线
- **实战意义**：趋势强弱分界线
- **识别规则**：
  1. 找到3个以上的波段高点
  2. 连线后观察价格是否受压
- **操作信号**：跌破生命线 = 减仓；突破生命线 = 加仓
- **失效边界**：震荡市中文线可能频繁穿越
- **案例**：富联生命线在200元附近（8/26回调至此获得支撑）

### 3. 攻击线（MA5）
- **定义**：5日移动平均线
- **计算公式**：MA5 = (今日+昨日+前日+前三日+前四日)收盘价 / 5
- **实战意义**：短期强弱分界
- **识别规则**：
  1. 价格 > MA5 = 短期强势
  2. 价格 < MA5 = 短期弱势
- **操作信号**：MA5向上 + 价格站上MA5 = 买入信号
- **失效边界**：震荡市中MA5频繁穿越，参考价值下降
- **案例**：胜宏MA5在258元，现价264已突破

### 4. 均线支撑（MA10/MA20/MA60）
- **定义**：10日/20日/60日移动平均线
- **计算公式**：MA_n = sum(近n日收盘价) / n
- **实战意义**：中期趋势判断
- **识别规则**：
  1. MA10向上 + 价格靠近MA10 = 短线买点
  2. MA20向上 + 价格回调至MA20 = 中线买点
  3. MA60向上 + 价格回调至MA60 = 长线买点
- **操作信号**：根据周期选择对应均线作为支撑参考
- **失效边界**：均线系统空头排列时支撑失效
- **案例**：天孚MA10在1800元附近，作为短线支撑参考

## 三、组合信号详细规则

### 1. 二波确认
- **定义**：突破前高后的二次确认
- **计算公式**：第二波涨幅 > 第一波涨幅的50% = 有效
- **实战意义**：上涨中继，趋势延续
- **识别规则**：
  1. 第一波上涨后回调
  2. 突破第一波高点
  3. 突破后放量（量比>1.5）
- **操作信号**：突破确认后买入
- **失效边界**：假突破（突破后快速回落）= 陷阱
- **案例**：通富 2026-07 第二波突破前高后继续上涨20%

### 2. 假突破（对倒典型信号）
- **定义**：价格快速冲高后快速回落
- **计算公式**：
  1. 单根K线涨幅 > 3%
  2. 随后2根K线回吐 > 70%涨幅
  3. 伴随量能异常放大（量比>3）
- **实战意义**：量化对倒的典型形态
- **识别规则**：
  1. 早盘快速拉升（9:30-10:00）
  2. 午后快速回落
  3. 收盘留下长上影线
- **操作信号**：出现假突破信号 = 观望/减仓
- **失效边界**：真突破也可能有盘中回落，需结合趋势判断
- **案例**：华建 2026-08-27 早盘冲高后回落，形成假突破

## 四、失效信号与替代方案

### 传统失效场景
| 传统信号 | 失效原因 | 替代方案 |
|----------|----------|----------|
| 倍量柱 | 量化对倒制造虚假放量 | 结合5分钟K线量价背离检测 |
| 高量柱 | 对倒导致高量但无真实买盘 | 检查量比是否真实（排除集合竞价影响） |
| 黄金线 | 量化程序化交易突破关键位后快速砸盘 | 等待右确认再操作 |
| 缩量止跌 | 阴跌过程中缩量非见底 | 配合百日低量柱判断 |

### 现代升级要点
1. **量柱判定**：必须用前复权数据，否则除权日前后数据失真
2. **对倒识别**：引入5分钟K线分析，检测脉冲-回落形态
3. **监管适应**：量化监管后（2026年8月），对倒减少，传统信号有效性提升
4. **环境优先**：先判断大盘环境（牛/熊/震荡），再选信号组合

## 五、实战检查清单

### 买入前检查（五层过滤网）
- [ ] 量学信号层：买入三问 + 位置<70% + 右确认三条件
- [ ] 大盘环境层：三线 + 四把体温计 + 环境三档
- [ ] 基本面层：非ST/*ST；PE/ROE可获取
- [ ] 情绪面层：大盘三线 + 涨跌家数比例
- [ ] 风险收益比层：≥2:1才出手

### 卖出前检查
- [ ] 是否跌破关键支撑位（生死线/止损线）
- [ ] 是否出现对倒信号（量价背离+长上影）
- [ ] 大盘环境是否转弱
- [ ] 是否达到目标价位（止盈区间）
