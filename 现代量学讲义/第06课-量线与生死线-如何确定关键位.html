第6课量线与生死线——如何确定关键位

现代量学实战体系 · 回答"右确认的锚从哪来" · 授课：黑马王子（张得一）
数据来源：本地行情数据库（8股=腾讯证券前复权接口，与看盘软件一致），截至2026-08-24收盘，逐日核验；均线为前复权收盘价计算

一、为什么必须先定线

上一课说了：右确认 = 一个左信号 + 一条生死线，盯着它直到站上或跌破。但你一定会追问：生死线从哪来？凭什么画在那儿？

如果生死线是随手画的，右确认就是空中楼阁。你盯一条自己都不信的线，等于没盯——那不是纪律，是自欺欺人。

所以这一课，把"定线"这一步彻底讲透。定线定得好，右确认才有意义。

二、生死线的本质：多空分水岭 + 集体记忆

想象股价是一只皮球，在房间里弹。天花板是顶部、地板是底部，中间还有一层电网——那是很多人买进卖出的成本区。

皮球弹到电网附近时：

  • 下面套牢的人：终于要回本了，赶紧跑 → 抛压；
  • 上面空仓的人：跌到这儿了，够便宜 → 承接。

两边一碰，皮球就在这里反复撞，撞完了决定方向。这条"电网"，就是生死线。

为什么生死线反复起效？因为人是有记忆的。

  • 套牢的人记得自己多少钱买的——回本就跑；
  • 空仓的人记得上次这里没跌下去——这次敢接。

结论：多空双方都认账的位置，才叫生死线。一条线只有你自己看得见、别人都看不见，它就不会起效——因为别人的买卖根本不会参考它。

三、四把尺子，按顺序用

尺子一：最近的箱体边沿（前高/前低）——最常用

找出最近这一波行情里，价格反复触到、却没过去的位置。被反复确认过的位置，就是"集体记忆"最强的位置。

工业富联（601138）：箱体下沿 64.51右证伪案例

数据来源：本地行情数据库，前复权，逐日核验

8/19破位前，股价在64.51 ~ 70.97 的箱体里来回晃了一个多星期，箱体下沿64.51（8/12最低价）被多次触碰未破。

8/19放量跌破64.51（量比1.06、收61.83）= 箱体下沿失守 = 右证伪。之后8/20-8/21在地量（量比0.56、1.02）下挣扎，8/24放量再破61.5，一路下行。

尺子二：高量柱的实顶——量学最核心

找最近量最大（量比最大）的那根K线，它的实顶（收盘价）就是生死线。口诀："高量不破，后市可期"。

为什么？高量柱那天换手巨大、筹码大量易主——那根K线的价位，就是新主力+接盘者的平均成本区。跌破它 = 这批人全被套 = 趋势坏了。

通富微电（002156）：8/17高量柱实顶 69.26启动→证伪案例

数据来源：本地行情数据库，前复权，逐日核验

8/17倍量涨停（量比2.09），当天换手巨大，收69.26。69.26就是那批"新主人"的成本线——如果启动是真，就不该跌破它。

8/18放量上攻到72.56（右确认），8/19却缩量跌停跌破69.26（收63.59，量比0.82）。跌破高量柱实顶 = 新主人也被套 = 启动证伪，必须走人。

尺子三：均线（20日/60日）——趋势温度计

  • 60日线 = 大生命线：收盘站稳之上 = 中长期强势；跌破 = 中长期转弱。
  • 20日线 = 短期生死线：短线进出的分水岭。

均线适合当"宏观背景"验证，和尺子一、二配合使用。多把尺子指到同一个位置时，那条线特别硬。

三条尺子全指向下方——均线死叉向下、箱体破位、价格在20/60日线之下。这种"多线合一"的位置，就是最硬的生死线：下方只剩60元整数关（心理位）作为最后的观察位。

尺子四：缺口 + 整数关口——补充

  • 向下跳空缺口的下沿：缺口是恐慌留下的"伤口"，价格反弹回来，上方套牢盘会砸，是压力位；
  • 整数关口（60、50、100）：心理价位，散户和主力都会盯，往往有挂单，是隐形支撑/压力。

四、三条铁律（画线之前先背下来）

铁律一：取近不取远。取最近一次碰撞的位置，别去翻几百天前的老黄历。远了筹码都换光了，"记忆"失效。

铁律二：取显不取冷。取一眼能看到的——箱体边沿、大阳大阴线、整数位。别画冷门指标算出来的线，没人认。

铁律三：一条就够。只画一条最关键的，最多两条（一条进攻线、一条防守线）。画了一堆线 = 等于没画——你会永远"既上又下"，自相矛盾。

五、三步实操法（小白落地版）

以后看任何一只股票，花一分钟定线：

  1. 画箱体：日K图上，找到最近这一波的高点和低点，画出箱体边沿（前高/前低）；
  2. 找高量柱：找出最近量最大那根K线，记下它的收盘价（实顶）；
  3. 对照验证：看这个价位是不是恰好靠近60日线或整数关口——多线合一 = 铜墙铁壁，取它；不重合，就取箱体边沿或高量柱实顶，哪个更近、更显眼用哪个。

六、用收盘价判定（和右确认连起来）

生死线定好了，纪律就一句话——用收盘价判定，别管盘中毛刺：

  • 收盘站上生死线 → 右确认 → 试探性进场；
  • 收盘跌破生死线 → 右证伪 → 放弃/离场；
  • 没上没下 → 空仓等，等本身就是答案。

一句话记住：生死线不是算出来的，是"最近、最显眼、量最大"的那个价位——多空双方都认账的位置，才是真线。
