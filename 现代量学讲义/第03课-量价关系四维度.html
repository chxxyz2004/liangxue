第3课量价关系四维度

现代量学实战体系 · 第一阶段 · 授课：黑马王子（张得一）
案例数据来源：新浪财经官方日K行情，逐日核验

一、先破一个迷思：量价没有"唯一答案"

新手喜欢背口诀：放量上涨=好，缩量下跌=坏。量学告诉你：这是最害人的简化。

量价关系是"四维"的，只看"量+价"两个点，等于只看了冰山一角。

要判断性质，必须同时看四个维度：

  1. 维度一：量与价（放还是缩？涨还是跌？）
  2. 维度二：量与位置（在高位还是低位？）
  3. 维度三：量与时间（持续几天？还是一天？）
  4. 维度四：量与性质（谁在买谁在卖？主力还是散户？）

四个维度全部对齐，才能下结论。任何一个维度缺失，结论都是猜测。

二、维度一：量与价——基础的四种组合

组合字面意思性质取决于其他三维
放量上涨分歧大+多方赢低位=启动，高位=出货
缩量上涨分歧小+多方赢惜售无抛压=健康，无量虚涨=危险
放量下跌分歧大+空方赢高位=派发，低位=恐慌杀跌
缩量下跌分歧小+空方赢无人接盘=阴跌，惜售=洗盘

同样"放量上涨"，低位是宝贝，高位是陷阱。这就是为什么必须进入维度二。

三、维度二：量与位置——最关键的一维

案例A：通富微电的"放量上涨"——低位是启动8月17日

数据来源：新浪财经官方日K，量比2.09

8月17日放量上涨（量比2.09，+10.01%涨停）收69.26元，位置是从55元平台刚启动的中低位。8月18日继续放量上涨（量比1.24）收70.66元，量价齐升。

四维判断：低位+放量+持续两天+主力抢筹 = 启动信号，教科书级的健康放量上涨。

案例B：通富微电的"放量"——高位是出货（同一只股票！）8月18-19日

数据来源：新浪财经官方日K，逐日核验

8月18日冲高72.56元后，8月19日放量跌停。前一天还在"放量上涨"，第二天翻脸。原因：8月18日的位置已接近前高密集区，高位放量，就是主力把筹码递给追高者。

同一个股票、同样的"放量"，一个位置是启动、一个位置是出货。这就是"位置决定性质"最直接的证明。

案例C：天孚通信的"高量见顶"——位置+时间双确认8月13-24日

数据来源：新浪财经官方日K，逐日核验

8月13日放量上涨（量比1.21）→ 8月14日缩量上涨（量比0.81）价涨量缩，量价背离（第一声警报） → 8月17日再放量冲高 → 8月18日高位放量滞涨（冲295元不封）（第二声警报） → 8月19日下跌 → 8月24日放量暴跌-8.63%。

完整链条：放量上涨→缩量背离→高位滞涨→放量下跌。四个维度都在说同一个故事：主力在出货。

四、维度三：量与时间——持续性是试金石

单日放量可能是噪音，持续的量能才是主力行为。用"左证明右确认"来说：

  • 一天的量 = 左（猜想）：今天放量只证明今天有资金，不证明明天还来；
  • 持续的量 = 右（确认）：连涨三天且量能每天配合，才确认主力真的在运作。
案例D：工业富联的"缩量磨底"被证伪8月20-24日

数据来源：新浪财经官方日K，逐日核验

8月20日缩量（量比0.56）企稳、8月21日温和小涨——这是"左"，只能说抛压减轻。但8月24日放量下跌（量比1.23）破位——"右"没来，反而来了放量下跌，前两天的缩量企稳被证伪。

教训：缩量企稳只是猜想，必须等放量上涨来确认。没确认前，一切都是猜测。

案例E：赛腾股份的超跌反抽——时间检验中8月19-24日

数据来源：新浪财经官方日K，逐日核验

8月19日跌停→8月20-21日缩量→8月24日放量翻红（量比1.38）。今天是"左"（第一天放量反弹），明天能否放量续涨是"右"。能不能成，明天看。

五、维度四：量与性质——谁在买谁在卖

盘面数据只告诉你"有多少量"，不直接告诉你"谁在买卖"。量学给你两个推断工具：

  • 工具1：量价背离看主力——价涨量缩=卖的人少（主力锁仓惜售），也可能是买盘衰竭（虚涨）；价跌量缩=没人愿卖，也可能没人愿买。低位是洗盘，高位是阴跌。
  • 工具2：融资余额看杠杆资金——今天复盘里胜宏科技融资余额从172亿回落到163.79亿、8月19日单日净偿还6.45亿，杠杆资金（最敏感的主力之一）在撤。融资撤退+高位放量=双确认出货。

六、四维综合：拼成一个判断

看任何一根K线，脑中同时跑四问：

  1. 量价：今天放量还是缩量？涨还是跌？
  2. 位置：这是高位还是低位？（前面是高量还是低量？）
  3. 时间：这现象持续几天了？第一天还是第N天？
  4. 性质：结合融资、板块、消息面，主力还是散户在主导？

四问答案对齐，才敢行动；对不齐，就观望。
