《五维看盘》讲义

量学核心理论升级 · 现代A股适配版

从四维到五维：增加"资金"维度，应对量化时代

一、为什么从四维升级到五维

1.1 传统四维的局限

传统四维看盘（从右到左、从上到下、从左到右、从下到上）的核心是量价阴阳循环。

但在现代A股市场，面临三大挑战：

挑战传统四维的问题
量化资金占比35-40%高频对倒制造虚假量价信号
流动性极度分化4000+中小票日成交不足5000万，量价信号失真
机构定价权转移散户占比降至18.6%，单纯看K线不够

1.2 成交额 vs 成交量的本质区别

关键认知：成交量（股数）≠ 资金规模 例1：低价股 股价10元 × 成交量100万股 = 成交额1000万元 例2：高价股 股价200元 × 成交量100万股 = 成交额2亿元 同样成交量，资金规模差20倍！ 只看成交量会严重误判高价股的资金力度。
"观察成交额能更真实地感知大资金的参与深度。"
——东方财富财富号《技术分析的八维共振》，2026-08-15

1.3 量化监管后的积极变化

2026年8月28日量化交易正式严管：
- 超高频策略生存空间被大幅压缩
- 盘中莫名其妙脉冲、毫无缘由闪崩会变少
- 技术分析干扰程度下降，信号有效性得到修复

二、五维看盘框架

2.1 五维定义

五维 = 量 + 价 + 时 + 空 + 资金 其中： - 量 = 成交量柱高度、相对5日均量倍数 - 价 = K线形态、影线、实体、均线 - 时 = 周期（短5-10/中20-60/长120-250）、趋势持续天数 - 空 = 250日百分位、距支撑/压力距离 - 资金 ⭐新增 = 主力12子状态、北向/量化流向、成交额结构

2.2 五维共振规则

至少3个维度同时指向同一方向，信号才可信。

2.3 五维共振示例：倍量柱信号验证

维度验证内容结论
量倍量柱（量比≥1.9）✅ 有异动
价阳线（close>open）✅ 多方占优
时处于低位盘整20日+✅ 时间充分
空250日百分位<33%✅ 低位安全
资金北向/主力同步净流入✅ 资金确认

五维共振 → 高可信度买入信号

三、各维度详解

3.1 第一维：量（成交量）

核心问题：有没有大资金动作？

量柱类型定义信号含义
倍量柱量比≥1.9 且收阳主力异动，重点关注
高量柱量比>3倍分歧极大，可能是顶部或底部
缩量柱量比<0.5观望情绪浓，趋势可能衰竭
梯量柱连续3日量比递增主力边拉边吸，趋势健康
口诀：量比>2有大动；持续放大是进场；持续萎缩快撤退

3.2 第二维：价（K线形态）

核心问题：多空谁占上风？

形态特征含义
大阳线涨幅>3%，实体饱满多头强势
长上影上影>实体2倍抛压重，警惕变盘
长下影下影>实体2倍支撑强，可能反弹
十字星实体极小多空平衡，变盘信号
连阳连续3日阳线多头趋势延续
口诀：大阳>3%多头强；长上影抛压重；连阳趋势要跟上

3.3 第三维：时（时间周期）

核心问题：行情到了什么阶段？

周期时间范围适用场景
短期5-10日震荡期高抛低吸
中期20-60日趋势明确时的持仓
长期120-250日转折点判断、大趋势
口诀：底部盘整>20日=筹码充分；高位横盘>20日=警惕变盘

3.4 第四维：空（空间位置）

核心问题：向上空间大还是向下大？

百分位位置信号含义
<33%低位（山脚）倍量柱/黄金柱=建仓信号
33-66%中位（半山腰）信号可信度打折，需右确认
>66%高位（山顶）倍量柱=可能出货，需警惕
口诀：<33%低位是机会；33-66%中位需确认；>66%高位要警惕

3.5 第五维：资金 NEW

核心问题：聪明的钱在做什么？

资金三层含义

第一层：成交额绝对值 - 判断资金是否真金白银进场 - 高价股必看成交额，不能只看成交量 第二层：资金流向结构 - 北向资金（外资风向标） - 主力资金（机构行为） - 量化资金（高频博弈特征） 第三层：资金一致性验证 - 量价信号 + 资金流向同向 = 高可信度 - 量价信号 + 资金背离 = 警惕假信号

主力资金12子状态识别

状态看到什么为什么怎么做
建仓期低位止跌，偶现倍量阳但不涨试探买入观察
洗盘期缩量阴跌数天磨耐心关键位不破就拿住
拉升期放量突破长期压力打开空间果断跟进
出货期高位放量滞涨派发筹码减仓/离场

量化资金行为识别

行为看到什么为什么怎么做
对倒造假量比>2涨跌<1%自买自卖假活跃不进场，紧止损
撤退离场缩量阴跌，反弹无量失去买方跟随减仓
试探建仓低位放量涨幅小测试抛压加入观察池
成交额优先原则：
高价股必看成交额！200元股票成交100万股=2亿元，10元股票成交100万股=1000万元。
同样成交量，资金规模差20倍！

四、五维实战操作步骤

4.1 盘前预案（五维扫描）

第一步：扫图识势（缩图看势） - 打开股票，缩图观察整体趋势 - 判断当前处于什么位置（低位/中位/高位） - 识别主要量线（峰顶线、谷底线、黄金线） 第二步：找柱识庄（放图察柱） - 放大查看最近30-60根K线 - 寻找倍量柱、黄金柱、关键量线 - 分析主力意图（吸筹/拉升/出货） 第三步：定计划（临界预判） - 上行找大阴实顶（压力位） - 下行找大阳实底（支撑位） - 制定买入价、止损价、目标价 - 五维共振检查：至少3维同向才出手

4.2 盘中盯盘（五维验证）

  • 关注一：量波形态 - 白线是否在黄线上方，红波多还是绿波多
  • 关注二：量价配合 - 价格上涨时量能是否放大
  • 关注三：成交额验证 - 高价股成交额是否同步放大
  • 关注四：关键位反应 - 价格回踩十字线后是否有反向运动
  • 关注五：资金流向 - 北向/主力是否有异动

4.3 盘后复盘（五维循环）

  1. 从右到左（时间回溯）：今日K线与历史相似形态对比
  2. 从上到下（空间定位）：当前价格在量线体系中的位置
  3. 从左到右（趋势演进）：本周趋势是否延续
  4. 从下到上（反弹动能）：反弹是否得到量能确认
  5. 资金维度验证：今日资金流向是否确认信号

六、常见误区与纠正

误区正确理解
只看K线不看量柱K线是表象，量柱是本质；量在价先
放量涨就追，放量跌就跑必须结合位置：低位放量是机会，高位放量是陷阱
只看成交量不看成交额高价股必须看成交额，否则资金力度误判

七、现代A股特殊陷阱识别

7.1 量化对倒制造的虚假信号

特征：

  • 量比>2，但涨跌<1%
  • 上影线/实体>2，且涨>0
  • 单根涨>3%随后2根回吐>70%

识别方法：看成交额是否同步放大；观察分时图脉冲特征；识别"假阳真阴"

7.2 流动性分层的误判风险

现象：龙头股成交额几十亿，量价信号清晰；4000+中小票日成交不足5000万，信号失真

应对：优先关注日均成交>1亿的标的；冷门股谨慎使用量学信号；用周线替代日线过滤噪音

7.3 抱团资金的"无量空涨"

现象：机构高度控盘，缩量创新高，看似强势实则跟风不足

应对：观察成交额是否同步放大；缩量创新高需右确认；高位缩量警惕"强弩之末"

八、五维看盘总结

8.1 核心口诀

量在价先定真伪，价随量动看强弱，
时位结合判阶段，空间位置分高低，
资金验证是根本，五维共振才出手。

8.2 实战检查清单

每次操作前，必须完成五维检查： □ 量：量柱是否异动？量比是否达标？ □ 价：K线形态是否健康？多空谁占优？ □ 时：周期是否充分？趋势是否明确？ □ 空：250日百分位是否安全？盈亏比是否合理？ □ 资金：成交额是否同步？北向/主力是否确认？ □ 共振：至少3维同向吗？

8.3 进阶要求

  1. 每只股票每次报告必须标出五维状态
  2. 每个信号必须经过五维共振验证
  3. 量化干扰严重的个股，资金维度权重提升至2维

十、结语

五维看盘是四维看盘在现代A股环境的升级版本。

核心变化：

  • 从四维 → 五维，增加"资金"维度
  • 从成交量优先 → 成交额优先（高价股）
  • 从单一维度判断 → 五维共振验证

核心理念不变：

  • 量价阴阳循环反映人性，千年不变
  • 就近对比原则依然有效
  • 位置决定性质是最高优先级
记住：量柱是有价的，价柱是有量的。看懂五维，叠加资金验证，才能在现代A股站稳脚跟。
