## 第三课：通用提示词的"三把黄金钥匙"

> 本章定位：提示词工程的核心方法论

### 第一节 如何正确看待提示词

提示词是人机对话的"源代码"，决定了AI输出的质量和方向。

**常见误区**：
- 提示词过于笼统，输出泛泛而谈
- 缺乏角色设定，AI不知道以什么身份回答
- 没有明确目标，输出偏离预期
- 一味堆砌细节，反而淹没重点

### 第二节 传统提示词的"三大缺陷"

| 缺陷 | 表现 | 后果 |
|------|------|------|
| 单一性 | 只有一个角度 | 输出片面 |
| 静态性 | 一成不变 | 无法适配不同场景 |
| 碎片化 | 零散无序 | 难以复用和沉淀 |

### 第三节 "通用提示词"的"三把黄金钥匙"

**第一把钥匙：提问**

提问是进入AI时代的通行证。好的提问应满足：

- 明确目标：知道想要什么
- 限定范围：给出边界条件
- 指定格式：要求输出格式
- 设定角色：赋予AI特定身份

**提问公式**：
> 角色 + 背景 + 任务 + 要求

**第二把钥匙：描述**

描述是驾驭AI能力的驾驶证。好的描述应满足：

- 信息完整：提供充分背景
- 层次清晰：结构化表达
- 语言准确：避免歧义
- 重点突出：主次分明

**第三把钥匙：指令**

指令是指挥AI运行的导航证。好的指令应满足：
- 动词明确：用具体的动作词
- 步骤清晰：分步骤执行
- 标准具体：明确评判标准
- 反馈可控：设置检查机制

### 第四节 "通用提示词"的"三个标准"

| 标准 | 要求 | 说明 |
|------|------|------|
| 完整性 | 要素齐全 | 角色、背景、任务、要求缺一不可 |
| 准确性 | 指向明确 | 无歧义，无模糊表述 |
| 可操作性 | 可执行 | AI能够理解和执行 |

### 第五节 "通用提示词"的"三元定律"

**三元定律**：提问 + 描述 + 指令 = 万能组合

| 组合方式 | 适用场景 | 示例 |
|----------|----------|------|
| 提问为主 | 信息获取类 | "请告诉我..." |
| 描述为主 | 内容创作类 | "请帮我写一份..." |
| 指令为主 | 任务执行类 | "请按以下步骤..." |
| 三者合一 | 复杂任务类 | "作为专家，根据以下背景，请按步骤完成..." |

## 第四课：三把黄金钥匙的万能组合

> 本章定位：综合运用三把钥匙解决实际问题

### 第一节 提问：进入AI时代的"通行证"

**提问的五个层次**：

| 层次 | 提问方式 | 示例 |
|------|----------|------|
| L1 | 是什么 | "什么是量子计算？" |
| L2 | 为什么 | "为什么量子计算重要？" |
| L3 | 怎么做 | "如何学习量子计算？" |
| L4 | 怎么样 | "量子计算发展现状如何？" |
| L5 | 假设 | "如果量子计算突破，会怎样？" |

### 第二节 表述：驾驭AI能力的"驾驶证"

**表述的四个维度**：

| 维度 | 说明 | 示例 |
|------|------|------|
| 背景维度 | 提供上下文 | "我正在准备一场关于AI的演讲..." |
| 角色维度 | 赋予身份 | "请作为资深AI专家..." |
| 任务维度 | 明确目标 | "请帮我撰写演讲大纲..." |
| 要求维度 | 设定约束 | "...控制在1000字以内，包含三个要点" |

### 第三节 指令：指挥AI运行的"导航证"

**指令的五要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| 动作词 | 明确的执行指令 | "分析""撰写""总结""对比" |
| 对象词 | 操作的目标 | "以下文本""这份报告" |
| 方式词 | 执行的方式 | "用表格""分三步""用比喻" |
| 标准词 | 质量的要求 | "准确""简洁""专业" |
| 格式词 | 输出的形式 | "Markdown""JSON""列表" |

### 第四节 "三把黄金钥匙"的万能组合

**万能提示词模板**：

```
作为【角色】，请根据【背景】，完成【任务】。
具体要求：
1. 【要求1】
2. 【要求2】
3. 【要求3】
请以【格式】输出。
```

**组合示例**：

```
作为资深股票分析师，请根据近期A股市场情况，
撰写一份涨停板伏击分析报告。
具体要求：
1. 分析近期涨停股的数量和板块分布
2. 总结出3个可复用的伏击模式
3. 给出5只值得关注的标的及其逻辑
请以表格+要点的方式输出，控制在1500字以内。
```

## 第五课：六套黄金魔方

> 本章定位：道（规律）层——提示词构建的底层逻辑

### 第一节 "一元树标魔方"

**核心思想**：从单一维度出发，建立清晰的提示词标准。

**应用公式**：
> 提示词 = 角色 + 任务

**示例**：
```
作为投资顾问，请分析这只股票的技术面。
```

### 第二节 "二元定位魔方"

**核心思想**：从两个维度定位问题，精确定义需求。

**应用公式**：
> 提示词 = 角色 + 背景 + 任务

**示例**：
```
作为资深程序员（角色），正在开发一个股票分析系统（背景），
请帮我设计数据库表结构（任务）。
```

### 第三节 "三元万象魔方"

**核心思想**：三个维度构建完整提示词，实现万能组合。

**应用公式**：
> 提示词 = 角色 + 背景 + 任务 + 要求

**示例**：
```
作为金融分析师（角色），A股市场近期波动较大（背景），
请帮我写一份投资策略报告（任务），要求包含市场研判、
板块分析和操作建议，控制在2000字以内（要求）。
```

### 第四节 "三要万通魔方"

**核心思想**：三个要素贯穿所有提示词场景，实现万通则达。

**三要素**：
1. 明确性：目标清晰
2. 具体性：细节到位
3. 可操作性：易于执行

### 第五节 "三维聚焦魔方"

**核心思想**：三个维度聚焦核心问题，提高输出质量。

**三维**：
- 纵向深入：追问到底
- 横向拓展：多维度关联
- 斜向创新：跨界思考

### 第六节 "三问探幽魔方"

**核心思想**：三个问题探索深层逻辑，发现隐藏规律。

**三问**：
1. 为什么是这样？
2. 还有其他可能吗？
3. 本质是什么？

## 第六课：六元轮动魔法

> 本章定位：法（策略）层——应对复杂场景的策略框架

### 第一节 提示词的"两大劲旅"

**劲旅一：结构化提示词**
- 采用固定模板
- 要素齐全
- 适合重复场景

**劲旅二：情境化提示词**
- 灵活变化
- 注重上下文
- 适合创新场景

### 第二节 "六个沃特"，万能通策

**六个沃特**（6W法则）：

| W | 含义 | 示例 |
|---|------|------|
| Who | 角色是谁 | 作为资深分析师... |
| What | 任务是什么 | 分析涨停板规律... |
| When | 时间背景 | 基于2025年市场... |
| Where | 场景是什么 | A股主板市场... |
| Why | 目的为什么 | 为了制定投资策略... |
| How | 怎么输出 | 以表格+要点方式... |

### 第三节 "六元框架"，容纳天下

**六元框架**：角色、背景、任务、要求、格式、约束

| 元 | 说明 | 必填 |
|----|------|------|
| 角色 | AI的身份 | 建议填 |
| 背景 | 上下文信息 | 建议填 |
| 任务 | 核心目标 | 必填 |
| 要求 | 具体标准 | 建议填 |
| 格式 | 输出形式 | 建议填 |
| 约束 | 限制条件 | 可选 |

### 第四节 "六元指令"，勇夺冠军

**六元指令**：明确动作、指定对象、说明方式、设定标准、规定格式、添加约束

### 第五节 "六元法则"，清华定格

**六元法则**：完整、准确、可操作、可复用、可迭代、可扩展

### 第六节 "六元淘金"，越用越灵

**六元淘金**：通过反复实践，找到最适合自己场景的提示词组合。

## 第八课：六路破局魔型

> 本章定位：器（模型）层——解决实际问题的强大工具

### 第一节 "行动链魔型"助公众号3个月涨粉80万

**行动链公式**：热点 → 观点 → 论证 → 行动

**应用**：
1. 追踪当日热点话题
2. 提出独特观点
3. 用案例和数据论证
4. 引导读者互动

### 第二节 "信任链魔型"助小红书1个月涨粉25万

**信任链公式**：真实经历 → 实用方法 → 效果验证 → 情感共鸣

**应用**：
1. 分享真实个人经历
2. 提供可复制的方法
3. 展示前后对比效果
4. 建立情感连接

### 第三节 "计划链魔型"助头条号2个月涨粉50万

**计划链公式**：目标 → 计划 → 执行 → 反馈 → 调整

**应用**：
1. 设定明确的内容目标
2. 制定周/月发布计划
3. 按执行节奏发布内容
4. 根据数据反馈调整

### 第四节 "因果链魔型"助视频号30天涨粉20万

**因果链公式**：现象 → 原因 → 方法 → 结果

**应用**：
1. 呈现引人入胜的现象
2. 分析背后的原因
3. 给出解决方案
4. 展示预期结果

### 第五节 "注意链魔型"助百家号1个月涨粉15万

**注意链公式**：悬念 → 铺垫 → 揭示 → 升华

**应用**：
1. 制造悬念吸引注意
2. 逐步铺垫信息

## 第九课：三招化解AI幻觉

> 本章定位：避坑指南——防范AI输出错误信息

### 第一节 人工智能的"三大缺陷"

| 缺陷 | 表现 | 危害 |
|------|------|------|
| 幻觉 | 编造不存在的事实 | 误导决策 |
| 偏见 | 输出带有倾向性的内容 | 不公平判断 |
| 过时 | 知识截止日期限制 | 信息滞后 |

### 第二节 面对幻觉的"五个明白"

| 明白 | 说明 |
|------|------|
| 明白一 | AI不是全知全能，它有知识边界 |
| 明白二 | AI会编造信息，需交叉验证 |
| 明白三 | AI的输出仅供参考，最终判断在人 |
| 明白四 | 重要信息必须来自权威来源 |
| 明白五 | 幻觉是技术特性，不是人为错误 |

### 第三节 规避幻觉的"三五法则"

**三查**：
1. 查事实：关键数据需核实
2. 查重源：多方来源印证
3. 查逻辑：推理过程是否合理

**五不**：
1. 不轻信：对AI输出保持怀疑
2. 不盲从：有独立判断
3. 不复述：未经核实不传播
4. 不依赖：重要决策不单一依赖
5. 不遗忘：保留原始信息溯源

### 第四节 化解幻觉的"三个魔法"

**魔法一：追问法**
- 连续追问，检验一致性
- 如果发现矛盾，说明存在幻觉

**魔法二：角色扮演法**
- 让AI扮演不同角色
- 从多角度交叉验证

**魔法三：来源追溯法**
- 要求AI提供信息来源
- 核实引用的准确性

## 第十二课：提示词创建的"十大戒律"

> 本章定位：提示词工程的最佳实践

### 第一节 一个奇怪问题

**问题**：同样的提示词，为什么不同人用效果差异巨大？

**答案**：提示词的质量取决于使用者的认知水平和表达能力。

### 第二节 十大黄金戒律

| 戒律 | 内容 | 说明 |
|------|------|------|
| 戒律一 | 明确角色 | 始终给AI设定角色 |
| 戒律二 | 提供背景 | 充分的上下文信息 |
| 戒律三 | 具体任务 | 任务描述清晰具体 |
| 戒律四 | 格式要求 | 规定输出格式 |
| 戒律五 | 分步执行 | 复杂任务分步骤 |
| 戒律六 | 验证输出 | 重要信息交叉验证 |
| 戒律七 | 迭代优化 | 不断调试提示词 |
| 戒律八 | 积累模板 | 建立提示词库 |
| 戒律九 | 避免歧义 | 用词准确无歧义 |
| 戒律十 | 保持简洁 | 不必要的细节不要加 |

### 第三节 减法哲学与认知升维

**减法哲学**：
- 提示词不是越复杂越好
- 删掉不必要的修饰
- 保留核心要素
- 追求极简精准

**认知升维**：
- 从"问什么答什么"到"引导AI思考"
- 从"单次交互"到"多轮对话"
- 从"被动接收"到"主动构建"
- 从"工具使用"到"人机共生"
