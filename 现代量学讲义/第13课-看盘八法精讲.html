一、看盘八法总览

看盘八法 = 看大势 + 看位置 + 看量柱 + 看价柱 + 看量线 + 看量波 + 看买卖 + 看心态

八法不是并列关系，是递进关系。从宏观到微观，从市场到个股，从客观到主观，每一步都建立在前一步之上。

八法递进逻辑

1
看大势
大盘环境 + 涨跌家数 + 黄白线 + 量能

回答："今天能做吗？"

2
看位置
位置百分位 + 高中低 + 趋势方向

回答："这只股现在贵不贵？"

3
看量柱
高量柱 + 将军柱 + 黄金柱 + 缩量

回答："主力在干什么？"

4
看价柱
阴阳 + 实体 + 上影下影 + 缺口

回答："K线说了什么？"

5
看量线
生死线 + 均线 + 趋势线 + 箱体

回答："关键位在哪里？"

6
看量波
分时图 + 开盘30分钟 + 黄白线

回答："现在该进还是该出？"

7
看买卖
阳胜进 + 阴胜出 + 止损止盈 + 买入三问

回答："信号出了没有？"

8
看心态
心理10题 + 止损纪律 + 落袋规则

回答："我手痒了吗？"

💡 八法口诀：大势定生死，位置定贵贱，量柱定主力，价柱定方向，量线定关键，量波定时机，买卖定信号，心态定成败。

二、第一法：看大势

2.1 看什么

  • 大盘三线：上/中/下线，指数落哪段
  • 涨跌家数：涨停/跌停、涨/跌家数对比
  • 黄白线：白线=权重、黄线=中小盘
  • 量能：市场总成交额，放量还是缩量

2.2 怎么判断

大势信号含义操作
指数红+涨多跌少+黄白齐升+放量真涨可做
指数红+跌多涨少+白线在上假涨（权重护盘）减仓
指数绿+涨多跌少+黄线在上假跌（小票抗跌）观望
指数绿+跌多涨少+缩量真跌空仓

2.3 实战案例

8/17 大势强 → 可做

三大指数齐涨，涨停>50家，黄白线齐升，放量 → 大势强，仓位6-8成。

8/19 大势弱 → 空仓

三指数大跌，跌停>30家，黄白线齐跌，缩量 → 大势弱，空仓最安全。

8/24 大势震荡偏弱 → 2-4成

指数震荡，涨跌各半，黄白线纠缠，缩量 → 分化市，上限2-4成。

三、第二法：看位置

3.1 位置百分位

位置百分位 = (当前价 - 250日最低) / (250日最高 - 250日最低) × 100%

三档：<40% 低位 40-70% 腰部 >70% 高位

3.2 位置定性质

位置性质策略
<40%低位吸筹区关注阳胜进信号
40-70%腰部持有区持有为主，不加仓
>70%高位风险区只止盈，不追高

3.3 实战验证

天孚 8/4 位置46%（腰部） → 涨+32%

腰部启动，阳胜进信号有效。位置<70%，可做。

天孚 6/25 位置89%（高位） → 跌-47%

高位放巨量，主力出货。位置>70%，只出不做。

四、第三法：看量柱

4.1 四种量柱

量柱类型特征含义
高量柱一段时期量最大主力成本线，实顶=生死线
将军柱放量大阳线（量比≥1.3）吸筹信号，黄金柱底座
黄金柱将军柱+3日缩量不破吸筹完毕，即将拉升
缩量柱量比<0.8，递减抛压枯竭，蓄势待发

4.2 量柱三步法

1
位置过滤

先看位置百分位，>70%的高位量柱一律当出货，不做黄金柱判断。

2
量比数字化

看量比：1.2-2.0温和放量（好）；>2.0需警惕；>3.0对倒风险。

3
不破关键位

将军柱后3日缩量不破实底 → 黄金柱成立。破了 → 失败。

📊
量柱识别练习
截图任务：在持仓股中找到一根高量柱，标注实顶价格

五、第四法：看价柱

5.1 K线六要素

要素看什么实战意义
阴阳收涨=阳线（红）/收跌=阴线（绿）大方向多空
实体开盘到收盘的距离实体越长=力量越强
上影最高价到实体顶上影长=上方有抛压
下影实体底到最低价下影长=下方有支撑
缺口今日低>昨日高（或反之）跳空=情绪极端
量比今日量/5日均量放量还是缩量

5.2 关键K线形态

看涨形态

  • 大阳线：实体长>5%，量比1.2-2.0 → 阳胜进信号
  • 长下影阳线：下影>实体2倍 → 下方支撑强
  • 缩量十字星：低位缩量+十字星 → 变盘向上

看跌形态

  • 大阴线：实体长>5%，量比>1.2 → 阴胜出信号
  • 长上影阴线：上影>实体2倍 → 上方抛压重
  • 放量滞涨：量比>2但涨幅<1% → 出货

六、第五法：看量线

6.1 四把尺子定生死线

尺子怎么找优先级
箱体边沿近3个月反复触及的高/低点第1优先
高量柱实顶一段时期量最大那根柱的实顶第2优先
20/60日均线通达信默认均线第3优先
缺口/整数关口跳空缺口、整数价位第4优先

6.2 多线合一

多线合一 = 多把尺子指向同一价位 → 该价位是强生死线

例：箱体上沿68.5 + 高量柱实顶69.0 + 60日均线67.8 → 三线在68-69区间合一 → 这个区域就是强压力。

💡 取近取显：如果多把尺子不合一，取最近、最明显的那个。不要画5条线自己打架。

七、第六法：看量波

7.1 分时图三看法

1
看开盘30分钟

09:30-10:00的量价走向定当天强弱。放量涨=强，缩量跌=弱。

2
看黄白线

白线=分时均价，黄线=分时走势。黄线在白线上方=强势，下方=弱势。

3
看量峰

分时量柱的峰谷。放量峰+价涨=健康；放量峰+价跌=出货。

7.2 量波实战

开盘30分钟定方向

  • 放量涨：量比>1.5+涨幅>1% → 当天偏多
  • 放量跌：量比>1.5+跌幅>1% → 当天偏空
  • 缩量震荡：量比<1.0+涨跌<0.5% → 观望

八、第七法：看买卖

8.1 买入三问

买入三问 = 位置<70%？+ 量比1.5-2.0？+ 有右侧确认？

三问全过=可买；两问过=观望；一问以下=不做。

8.2 卖出两信号

信号条件操作
阴胜出量价双跌无条件先走
破关键位跌破生死线止损出局
止盈达到目标价分批落袋

8.3 买卖纪律

⚠️ 铁律：买入前必过三问，卖出时信号一出必走。犹豫=亏钱。

九、第八法：看心态

9.1 心态三病根

病根表现药方
太急追涨、频繁交易买入三问+限制出手次数
太贪不止盈、死扛落袋规则+阴胜出止损
太迷信看形态就买双向验证+量比过滤

9.2 心态体检10题（回顾第12课）

每天收盘必做：追涨/垂死/懊恨/报复/违纪/落袋/迷信/过度/分心/情绪。6分+=熄盘24小时。

💡 心态最难练：不是看一次就会，是每天做心理体检，坚持100天形成肌肉记忆。

十、八法实战串联（完整案例）

赛腾 8/12 完整八法推演

1
看大势：8/12大势偏强

三大指数涨，涨停>40家，黄白齐升 → 可做，仓位4-6成。

2
看位置：赛腾位置约35%

250日位置百分位35%，低位区 → 可关注买入信号。

3
看量柱：8/12将军柱

放量大阳线，量比1.63 → 将军柱成立（量比1.2-2.0理想区间）。

4
看价柱：阳胜

量价双涨，阳线实体>3% → 阳胜进信号。

5
看量线：生死线在45.6

箱体下沿+高量柱实底合一 → 生死线45.6，站稳可买。

6
看量波：开盘放量涨

09:30-10:00量比>1.5+涨幅>1% → 当天偏多。

7
看买卖：买入三问全过

位置35%<70% ✅ / 量比1.63在1.5-2.0 ✅ / 阳胜右侧确认 ✅ → 可买。

8
看心态：不急不贪

按计划执行，不追涨、不死扛 → 心态过关。

结果：8/12买入 → 次日确认 → +13.8%止盈。八法贯通，信号有效

通富 8/17 八法推演（失败案例）

  • 大势：8/17大势强但分化 → 小心
  • 位置：通富位置约72% → 高位区
  • 量柱：量比2.09 → 超过2.0警戒线
  • 价柱：放量滞涨 → 出货嫌疑
  • 买卖：买入三问不过（位置>70%） → 不该买

结果：追板买入 → 次日大跌-11.6%。八法不过，强行操作

十三、本课核心要点

递进关系 八法是递进，不是并列。从大势到心态，每步建立在前步之上。

大势定生死 第一法不过，后面七法白看。大盘弱=空仓。

位置定贵贱 >70%高位只出不进，<40%低位才关注买入信号。

量柱定主力 高量柱实顶=主力成本=生死线。

买卖定信号 买入三问全过才动手，阴胜出无条件先走。

心态定成败 八法全会但心态崩=照样亏。每天心理体检。
