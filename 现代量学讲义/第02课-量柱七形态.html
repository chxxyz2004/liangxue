一、先立一个总纲：量柱是什么？

量柱，就是每根K线下面那根高低不一的"柱子"，代表当天的成交量。新手看量柱，只看到"高高低低"；量学看量柱，看到的是一群人在这个价位上交换了多少筹码、谁在买、谁在卖、谁更有底气。

记住第1课的心法：量是卖出来的。

每一根量柱的高度，本质上反映了当天有多少卖方愿意在这个价格交出筹码，又有多少买方敢于接住。所以量柱从来不单纯代表"人气"，它代表的是多空在这个价位上的分歧强度。

量柱不能只看高低，一定要结合位置和前后关系——这正是第4课"位置决定性质"的地基。判断"高量、低量、倍量"，一律以"较前一日的量比"为准，不凭感觉。

1. 高量柱：分歧的顶点

高量柱是七种量柱里"信息量最大"的一根。它的本质是当天有一大批人愿意卖，又有一大批人愿意买，双方在这个价位上硬碰硬。它是分歧，不是共识。

案例：胜宏科技（300476）高位天量后缩量阴跌

数据来源：新浪财经官方日K行情，逐日核验

8月13日，胜宏科技放出近期局部高量柱（52.2万手，量比1.31，对应成交额约145亿元），随后股价进入阴跌：8月19日大跌7.67%收245.38元，量能一路递减（8月18日31.5万手 → 8月21日22.9万手，量比0.77）。

用"卖在买先"来看：8月13日这根高量柱是一批获利筹码集中兑现的地方，之后缩量阴跌说明买盘没有跟进。配合融资余额从172亿元高位回落到163.79亿元、8月19日单日融资净偿还6.45亿元——杠杆资金在主动撤退。

结论：高位高量 + 后续缩量阴跌 + 融资撤退 = 典型的高位派发后走弱。高量柱本身不骗人，骗人的是把它当成"主力进场"的解读。

2. 低量柱：寂静的背后

低量柱的本质是当天愿意卖的人很少，愿意买的人也很少。但低量柱有两种完全相反的性质：一种是洗盘后的缩量企稳（好兆头），一种是没人要的缩量阴跌（坏兆头）。区别就看位置和方向。

案例：工业富联（601138）回调后的地量企稳

数据来源：新浪财经官方日K行情，逐日核验

8月20日，工业富联在从68元上方回落后，放出近期地量（78.1万手，量比0.56），收62.13元；8月21日探底回升收62.84元，量能仍未放大（79.4万手）。公司在61.35—61.97元区间实施回购托底。

它的含义是：该卖的在62元附近卖得差不多了（抛压枯竭），但买盘也还没大举进场。低量柱告诉我们的是"跌不动了"，但"跌不动"不等于"马上涨"——这就要用到第5课"左证明右确认"：低量只能证明抛压减轻，必须等后续放量突破才能确认新资金进场。

3. 平量柱：主力的呼吸声

平量柱是连续几天量能几乎拉平。它的本质是多空达到动态平衡，往往暗示主力控盘程度高、在耐心吸筹或洗盘。市场最热闹的时候不会有平量，平量只出现在"大资金不慌不忙"的阶段。

案例：天孚通信（300394）高位平量横盘后被打破

数据来源：新浪财经官方日K行情，逐日核验

8月20日、21日，天孚通信量能近乎持平（51.7万手、50.4万手，量比0.82、0.98），价格在273—276元窄幅横盘，属于高位平量消化浮筹的阶段。

然后呢？8月24日放量下跌（64.5万手，量比1.28），股价大跌5.01%收249.50元——平量横盘一旦被放量打破，方向往往就来了。这次选的方向是向下。所以平量本身中性，它真正的意义是"僵持等待选择方向"。

4. 梯量柱：情绪在升级

梯量柱是量能像楼梯一样逐级放大。它的本质是买卖力量一轮比一轮猛，市场情绪在升级。但梯量柱的关键不在梯子本身，而在梯子爬到顶端之后，接的是什么。

案例：赛腾股份（603283）梯量拉升后高位跌停

数据来源：新浪财经官方日K行情 + 同花顺融资数据

8月12日、13日，赛腾股份量能逐级放大形成梯量（24.2万手、36.3万手，量比1.63、1.50），股价从43.86元涨到48.25元；8月18日再度放量冲高51.52元（量比1.17）。期间融资余额突破12亿元、占流通市值超7%、处历史90%分位以上——杠杆资金逐级加码。

然后呢？8月19日，赛腾股份跌停（收46.37元），主力资金净流出2.39亿元。梯量柱爬到顶端，接的是一根断头铡刀。这是量化时代最经典的教训：融资盘堆出来的量能，一旦资金转向，崩塌速度极快。

5. 缩量柱：安静的两种读法

缩量柱是量能逐步递减。它的本质是参与的人越来越少。但"人少"分两种：一种是上涨中的缩量回踩（惜售，好事），一种是下跌中的缩量阴跌（无人接盘，坏事）。

案例：通富微电（002156）跌停后的缩量反抽失败

数据来源：新浪财经官方日K行情，逐日核验

8月19日通富微电跌停（收63.59元，149.9万手）；8月20日转为宽幅震荡，量能萎缩至122.9万手（量比0.82），收63.15元；8月21日继续缩量（96.9万手，量比0.79）。

用"卖在买先"解读：跌停次日缩量反抽，是跌停前的获利盘借反弹出货，不是买盘回来了。这种"缩量反抽失败"形态，量学称之为"回光返照"。要确认真正止跌，必须等一根放量阳线站回关键位——在此之前，缩量只能代表"抛压暂缓"，不能代表"反转"。

6. 倍量柱：突变时刻

倍量柱是量能突然放大到前一日2倍左右及以上。它的本质是当天发生了突发性的多空冲突。倍量柱是中性的，它的性质完全由位置决定：低位倍量常常是主力启动信号，高位倍量常常是主力出货动作。

案例：通富微电（002156）8月17日倍量启动

数据来源：新浪财经官方日K行情，逐日核验

8月17日，通富微电放出倍量柱（147.6万手，量比2.09），股价大涨收69.26元；8月18日继续放量（183.8万手）收70.66元，量价齐升——低位（上涨初期）倍量+量价共振，是典型的资金抢筹启动信号。

但随后8月19日跌停收63.59元，说明这波启动在70元上方遭遇巨大抛压，未能延续。倍量柱只告诉你"这里有突变"，它能不能变成趋势，还要看后面量价是否持续共振——这正是"左证明右确认"的体现。

案例：长电科技（600584）8月17日放量冲高 → 滞涨 → 回落

数据来源：新浪财经官方日K行情，逐日核验

真正的放量发生在8月17日：长电科技放出局部高量柱（191.2万手，量比1.67），大涨收85.85元；8月18日冲高87.50元后滞涨回落（150.8万手，量比0.79），收85.42元；8月19日直接大跌收77.74元。

再看业绩公布当天：8月21日公司披露半年报（归母净利润同比增长79.41%，二季度环比再增90%），但当天缩量（97万手，量比0.79）冲高至80.50元后回落，收78.57元不涨反跌。业绩利好 + 缩量冲高回落 = 没有增量资金愿意承接，利好出尽。

正确的量学读法是：8月17日放量冲高是主升的末端情绪，8月18日量能萎缩滞涨（高量滞涨）是警示信号，8月19日大跌确认见顶回落，8月21日缩量冲高回落则是利好无法兑现的"回光返照"。全程量能的逐步递减，配合价格重心下移，才是这段行情真正的量价语言。

7. 黄金柱：最珍贵的形态（预告）

黄金柱是七种量柱里唯一"带结构"的形态：先一根倍量柱（或高量柱）启动，随后连续3天以上缩量，但价格不破启动柱的底线。它的本质是主力真金白银进场后，用缩量洗盘把浮筹清洗干净，同时锁住筹码。

黄金柱 = 倍量启动 + 缩量回踩 + 不破关键位

这是量学最核心的"地基结构"，第6、7课会专门展开讲它的画法和买卖纪律。今天你只需要记住：当一只股票出现"放量涨一天、缩量跌几天但不破位"的结构，往往是主力在告诉你：我进来了，但我不想让你轻易搭车。

四、一句话方法论

看任何一根量柱，永远按这个顺序问自己：

  1. 先算量比：它较前一日是放、缩、平、倍？（不凭感觉，看数字）
  2. 它出现在高位还是低位？（位置决定性质）
  3. 它后面紧接着的量柱在放大还是缩小？（量价共振还是孤量）
  4. 有没有价格结构的突破或破位来确认？（左证明右确认）

七种量柱，本质是七个"体温计读数"，读数本身无意义，结合位置、前后关系和价格结构才有意义。

今日作业

  1. 量柱分类练习：打开你关注的8只算力股日K线图，把8月11日以来的每一根量柱按七形态标出（必须用软件里的成交量数字算量比，不凭感觉），然后告诉我：每只股票最近的走势，主导的是哪一种量柱？
  2. 找两个高量柱：在你关注的股票里，找一根你判断为"主力出货"的高量柱、一根判断为"主力启动"的高量柱，分别说明理由（结合位置+量比）。
  3. 想一想：为什么"跌停次日缩量反抽"不能当成反转信号？（提示：用"卖在买先"的逻辑回答）
