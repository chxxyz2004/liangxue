一、上节回顾

⚖ 定律第1课的三先规律是量学的根。其中"卖在买先"直接决定本课怎么读量柱：每一根量柱的高度，反映的是当天有多少卖方愿意在这个价位交出筹码，又有多少买方敢于接住。量柱代表多空在这个价位上的分歧强度，它从不单纯代表"人气"。

二、传统原理

🏷 传统量学量学把单根量柱归为七种基本形态，每种形态是一种"体温计读数"。注意定义一律以较前一日的量比为准，不凭感觉。

形态定义（以量比判定）本质含义关键看点
高量柱量能明显大于前几日（局部峰量）多空分歧达到顶点出现在哪里？之后3天能否守住
低量柱量能明显小于前几日（局部地量）多空都在观望是洗盘还是没人要？
平量柱连续几天量能几乎相等供需平衡、主力控盘出现在整理的末端还是顶部？
梯量柱量能逐日递增，像台阶买卖力量逐步升级后面接的是缩量还是高量？
缩量柱量能逐日递减抛压减轻或买盘犹豫缩量回踩还是缩量下跌？
倍量柱量能达前一日2倍左右及以上突发强烈多空冲突是启动信号还是出货动作？

8/13这根高量柱，是一批获利筹码集中兑现的地方。之后量能一路递减（8/18的31万手→8/21的23万手）、价格阴跌破位。用"卖在买先"读：高位高量 + 后续缩量阴跌 = 典型的高位派发后走弱。高量柱本身不骗人，骗人的是把它当成"主力进场"。

2. 低量柱：寂静的背后

案例：工业富联（601138）回调后地量企稳（后被证伪）数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/19 大跌61.831391.06-6.60%
8/20 地量62.13780.56+0.49%
8/21 探底回升62.84791.02+1.14%
8/24 放量破位60.40981.23-3.88%

8/20的量比0.56是地量，含义是"跌不动了"——该卖的卖得差不多了，抛压枯竭。但"跌不动"不等于"马上涨"：买盘并未大举进场，8/24放量破位把企稳证伪。教训：低量只证明抛压减轻，必须等后续放量突破才能确认新资金进场（呼应第5课"左证明右确认"）。

3. 平量柱：主力的呼吸声

案例：天孚通信（300394）高位平量横盘后被放量打破数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/20276.25520.82-0.41%
8/21 平量273.08500.98-1.15%
8/24 放量向下破位249.50641.28-8.63%

8/20-8/21量能近乎持平（52、50万手），价格窄幅横盘，属高位平量消化浮筹。8/24放量下跌（量比1.28）直接向下破位——平量僵持一旦被放量打破，方向就来了。平量本身中性，意义是"僵持等待选择方向"。

4. 梯量柱：情绪在升级

案例：赛腾股份（603283）梯量拉升后高位跌停数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/12 梯量第1级46.44241.63+5.88%
8/13 梯量第2级46.27361.50-0.37%
8/18 冲高51.52331.17+4.12%
8/19 跌停46.37310.93-10.00%

8/12-8/13量能逐级放大形成梯量（24、36万手），价格上行；8/18再度放量冲高51.52元。但梯量柱爬到顶端，接的是一根断头铡刀：8/19直接跌停。关键看梯子爬完之后接什么——接缩量回踩可能是蓄势，接高量滞涨或大跌就是顶部。

5. 缩量柱：安静的两种读法

案例：通富微电（002156）跌停后的缩量反抽失败数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/19 跌停63.591500.82-10.01%
8/20 缩量63.151230.82-0.69%
8/21 缩量63.88970.79+1.16%
8/24 续跌61.24910.94-4.13%

跌停次日缩量反抽，量学叫"回光返照"：这是跌停前的获利盘借反弹出货，不是买盘回来了。缩量只能代表"抛压暂缓"，要确认止跌必须等一根放量阳线站回关键位。8/24续跌印证。

6. 倍量柱：突变时刻

案例：通富微电（002156）8/17 低位倍量启动（但未延续）数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/1462.96710.77+1.19%
8/17 倍量涨停69.261482.09+10.01%
8/18 续放量70.661841.24+2.02%
8/19 跌停63.591500.82-10.01%

8/17倍量（量比2.09）+涨停，量价共振，看着是启动。但8/19跌停说明70元上方遭遇巨大抛压，启动未能延续。倍量柱只告诉你"这里有突变"，能不能变趋势还要看后续确认（左证明右确认）。

案例：长电科技（600584）8/17放量冲高 → 滞涨 → 见顶回落数据：前复权

数据来源：本地行情数据库（腾讯前复权），逐日核验

日期收盘量(万手)量比涨跌
8/17 放量冲高85.851911.67+9.07%
8/18 滞涨85.421510.79-0.50%
8/19 大跌77.741591.06-8.99%
8/21 业绩利好缩量冲高回落78.57970.79-1.14%

数据铁律教训（历史红线①）：8/21业绩利好当天量比0.79，是缩量冲高回落，不是倍量。判定量柱必须算量比，否则就会把"缩量利好出尽"误读成"倍量启动"。正确的量学读法：8/17放量冲高是主升末端情绪，8/18量能萎缩滞涨是高量滞涨警示，8/19大跌确认见顶，8/21缩量冲高回落是"回光返照"。

7. 黄金柱：最珍贵的结构（第7课已详讲）

黄金柱 = 倍量启动 + 缩量回踩 + 不破关键位

这是量学最核心的"地基结构"。第7课已用三个前复权案例（天孚8/4黄金柱成功、天孚6/25与通富7/21假黄金柱失败）讲过它的三步判定法。今天你只需要记住："放量涨一天、缩量跌几天但不破位"往往就是主力在说：我进来了，但我不想让你轻易搭车。

四、现代升级结论（含三查）

结论三查：证据
✅ 七种量柱基本形态：仍有效案例：本课七形态均以2026年8月真实盘面逐日核验（胜宏高量派发、富联低量企稳后被证伪、天孚平量破位、赛腾梯量跌停、通富缩量反抽失败、通富/长电倍量分化）；机理：量柱反映多空分歧强度的本质不变；边界：单根量柱无意义，必须结合位置+前后关系+价格结构。
⚠️ "高量=主力进场"等直觉解读：部分失效，需修正案例：胜宏8/13高量柱实为派发、长电8/17放量冲高实为见顶；机理：量化时代高量柱可能是对倒/机器人高频制造，不再天然代表"主力吃货"；修正：一律先算量比、先看位置，再读含义。
❌ 凭感觉看量柱（不含量比数字）：已失效，需替代案例：长电8/21缩量被误读为倍量（历史红线①）；机理：感觉会被K线高度欺骗，除权股尤其如此（必须用前复权）；替代：全部用本地库量比数字判定，数据铁律。

五、本课定律应用

⚖ 定律量柱七形态不是孤立的形态学，它全程调用三先规律：

关联定律如何体现
卖在买先读每一根量柱先问"是谁的卖盘"：高位高量=获利盘兑现（胜宏），低位倍量=抛压被抢筹（通富8/17）。
位置决定性质同样的倍量，低位是启动、高位是出货（通富8/17启动 vs 长电8/17见顶）。
左证明右确认低量只是左侧"抛压枯竭"信号，必须等右侧放量突破确认（富联8/20地量→8/24被证伪）。

六、失败案例对照（反幸存者偏差）

对比项通富8/17倍量（启动，后被证伪）赛腾8/12-8/13梯量（顶，跌停）
现象低位倍量涨停梯量冲高
量学读法抢筹启动信号情绪升级
后续8/19跌停，启动夭折8/19跌停，直接见顶
共同教训量柱形态只是"体温计读数"，本身不保证方向。必须有右侧确认（量价共振、站上关键位）才可信；位置越高，同样的"放量"越危险。

七、看盘/复盘实操

看任何一根量柱，永远按这个顺序问自己：

  1. 先算量比：它较前一日是放、缩、平、倍？（不凭感觉，看数字）
  2. 它出现在高位还是低位？（位置决定性质）
  3. 它后面紧接着的量柱在放大还是缩小？（量价共振还是孤量）
  4. 有没有价格结构的突破或破位来确认？（左证明右确认）

七种量柱，本质是七个"体温计读数"，结合位置、前后关系和价格结构才有意义。

今日盘面速递（2026-08-24，数据：前复权）

8股普跌（仅赛腾+1.82%），算力板块高量见顶特征明显。用本课"七形态"读：板块8/17集体放量（多只量比破1.5-2.0）是情绪顶点的高量柱，8/18集体滞涨是高量滞涨警示，8/19-8/24集体阴跌是见顶确认。全链条"高量分歧 → 量价背离 → 确认回落"三步走。今天多数股票处于"缩量下跌中继"，不是进场信号。

八、小测验（答对进下一课）

测验1：量柱的"高度"到底代表什么？
代表当天多空分歧强度（多少人愿卖、多少人敢接），不代表"人气"或"看好"。要用"卖在买先"解读：放量可能是集中甩货。
测验2：判定量柱形态的第一原则是什么？
算量比（较前一日的量/量比），不凭感觉。历史上"长电8/21缩量被误读为倍量"就是血泪教训，必须用前复权+数字判定。
测验3：为什么"跌停次日缩量反抽"不能当成反转信号？
因为缩量反抽是获利盘借反弹出货（卖在买先），不是买盘回来。缩量只代表抛压暂缓，必须等放量阳线站回关键位才确认反转。
