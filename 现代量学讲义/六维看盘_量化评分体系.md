# 六维看盘量化评分体系

> 版本：v1.0 · 2026-08-29
> 核心原则：总分100分，各维度权重不同，设置明确阈值

---

## 一、六维权重分配（总分100分）

```
┌─────────────────────────────────────────────────────────────┐
│                     六维权重总览                             │
├──────────┬─────────┬────────┬───────────────────────────────┤
│  维度    │  权重   │ 等级   │          核心作用             │
├──────────┼─────────┼────────┼───────────────────────────────┤
│ 环境维度 │  25分   │ 一票否决│ 决定去留、仓位、策略选择       │
│ 板块维度 │  20分   │ 关键筛选│ 决定主线热点、资金流向         │
│ 逻辑维度 │  15分   │ 持续性  │ 决定行情持续时间               │
│ 情绪维度 │  15分   │ 入场时机│ 决定买点在哪个情绪阶段         │
│ 资金维度 │  15分   │ 信号验证│ 决定技术信号是否可信           │
│ 技术维度 │  10分   │ 择时买点│ 决定具体入场价位和止损位       │
└──────────┴─────────┴────────┴───────────────────────────────┘
```

## 二、各维度详细评分标准

### 2.1 环境维度（25分）⭐ 最高权重

**核心问题**：现在是增量牛还是缩量熊？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| 大盘趋势方向 | 8分 | 周月均线多头排列且向上 | >20日均线=+4分，均线拐头向上=+4分 |
|  |  | 周月均线走平或向下 | 均线走平=-2分，均线向下=-4分 |
| 成交量趋势 | 8分 | 日均成交额>2万亿且放量 | >2.5万亿=+5分，>2万亿=+3分，>1.5万亿=+1分 |
|  |  | 日均成交额<1.5万亿且缩量 | <1万亿=-4分，<1.5万亿=-2分 |
| 市场宽度 | 9分 | 上涨家数占比 | >60%=+4分，40-60%=+2分，<40%=-2分 |

**一票否决条件**（直接判定"放弃操作"）：
- 大盘周月均线双死叉 + 成交量连续5日萎缩 → 总分<10分，强制空仓
- 上证指数跌破20周均线且放量下跌 → 总分<15分，减仓至2成以下

**得分分级**：
- **20-25分**：增量牛市，重仓出击（仓位6-8成）
- **15-19分**：震荡市，中等仓位（仓位3-5成）
- **10-14分**：弱势市，轻仓试探（仓位1-2成）
- **<10分**：熊市，强制空仓观望

---

### 2.2 板块维度（20分）

**核心问题**：资金在哪里？哪个板块主升？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| 主线清晰度 | 7分 | 是否有明确主线板块 | 主线清晰（3个以上板块联动）=+7分 |
|  |  | 主线模糊（单一板块独涨）=+3分 | 无主线=-3分 |
| 板块轮动节奏 | 6分 | 板块轮动是否有序 | 有序轮动（热点接力）=+6分 |
|  |  | 快速轮动（一日游）=+2分 | 无序轮动=-3分 |
| 资金集中度 | 7分 | 成交额占比前10%个股吸走多少资金 | >50%=+7分，30-50%=+4分，<30%=-2分 |

**得分分级**：
- **15-20分**：板块主线清晰，资金集中，重点关注
- **10-14分**：板块分化，选择性参与
- **<10分**：板块混乱，降低仓位或观望

**关键阈值**：
- 主线板块成交额占全市场>20% = 高确定性主线
- 板块指数站上20日均线 = 板块走强确认
- 板块龙头涨幅>30% = 板块进入高潮期，警惕退潮

---

### 2.3 逻辑维度（15分）

**核心问题**：为何而涨？持续性如何？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| 驱动类型 | 5分 | 政策/业绩/消息 | 政策驱动=+5分，业绩驱动=+4分，消息驱动=+2分 |
| 持续性判断 | 5分 | 长期成长还是短期炒作 | 产业周期3年以上=+5分，1-3年=+3分，<1年=+1分 |
| 预期差 | 5分 | 市场预期vs实际情况 | 超预期=+5分，符合预期=+3分，低于预期=-3分 |

**得分分级**：
- **12-15分**：逻辑强硬，可持续性强，重点关注
- **8-11分**：逻辑一般，注意风险控制
- **<8分**：逻辑薄弱，纯情绪炒作，谨慎参与

**关键阈值**：
- 政策级别：国家级产业政策 = 高持续性
- 业绩增长：营收/利润同比>30% = 业绩驱动确认
- 预期差：实际业绩>分析师一致预期 = 超预期

---

### 2.4 情绪维度（15分）

**核心问题**：市场处于什么情绪周期？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| 连板高度 | 5分 | 市场最高连板数 | ≥7板=+5分（高潮），5-6板=+3分，3-4板=+1分，<3板=-2分 |
| 涨停家数 | 5分 | 当日涨停股票数量 | ≥100只=+5分，50-100只=+3分，20-50只=+1分，<20只=-3分 |
| 赚钱效应 | 5分 | 昨日涨停今日溢价 | 昨日涨停今日平均涨>3%=+5分，>1%=+3分，<0%=-3分 |

**得分分级**：
- **12-15分**：情绪高潮期，加速赶顶，准备离场
- **9-11分**：情绪上升期，积极操作
- **6-8分**：情绪修复期，谨慎参与
- **<6分**：情绪冰点期，关注反转机会

**关键阈值**：
- **情绪亢奋线**：主板涨幅>3% + 创业板涨幅>5% → 阶段性顶部预警
- **情绪冰底线**：跌停家数>50只 + 连板高度<3板 → 底部信号关注
- **情绪拐点**：连板高度从<3板回升到≥5板 = 情绪修复确认

---

### 2.5 资金维度（15分）

**核心问题**：聪明的钱在做什么？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| 北向资金 | 5分 | 北向资金净流入 | >50亿=+5分，20-50亿=+3分，0-20亿=+1分，<0=-3分 |
| 主力资金 | 5分 | 大单净流入占比 | >3%=+5分，1-3%=+3分，0-1%=+1分，<0=-3分 |
| 成交额验证 | 5分 | 高价股成交额是否同步放大 | 同步放大=+5分，部分放大=+3分，背离=-3分 |

**得分分级**：
- **12-15分**：资金确认度高，信号可信
- **8-11分**：资金方向明确但力度一般
- **<8分**：资金分歧大，信号不可信

**关键阈值**：
- 北向资金连续3日净流入>20亿 = 外资看好确认
- 主力资金连续5日净流入 = 机构建仓确认
- 成交额放大但价格滞涨 = 主力出货预警

---

### 2.6 技术维度（10分）

**核心问题**：技术指标是否支持操作？

| 评分项 | 满分 | 得分标准 | 阈值 |
|--------|------|---------|------|
| K线形态 | 4分 | 主力行为信号 | 倍量柱+阳线=+4分，小倍阳=+3分，普通阳线=+1分 |
| 量价配合 | 3分 | 量价关系健康度 | 量价齐升=+3分，量增价涨=+2分，量价背离=-2分 |
| 支撑压力 | 3分 | 关键价位确认 | 回踩支撑不破=+3分，突破压力有效=+2分，破位=-3分 |

**得分分级**：
- **8-10分**：技术形态完美，高确定性买点
- **5-7分**：技术形态一般，需等待右确认
- **<5分**：技术形态不佳，放弃操作

**关键阈值**：
- 倍量柱定义：量比≥1.9且收阳
- 黄金柱定义：倍量后3日内回调≤1/3实顶
- 有效突破定义：收盘站上压力位>3%且量能放大

## 三、六维共振决策模型

### 3.1 总分计算

```
总分 = 环境分 + 板块分 + 逻辑分 + 情绪分 + 资金分 + 技术分

最高分：100分
最低分：-40分（各维度最低分之和）
```

### 3.2 决策阈值表

| 总分区间 | 等级 | 操作建议 | 仓位上限 | 风险等级 |
|---------|------|---------|---------|---------|
| **85-100分** | 极优 | 果断出击，抓住主升浪 | 8成 | 低风险 |
| **70-84分** | 优良 | 积极参与，顺势而为 | 6成 | 中低风险 |
| **55-69分** | 一般 | 选择性参与，控制仓位 | 4成 | 中风险 |
| **40-54分** | 偏弱 | 轻仓试探，设紧止损 | 2成 | 中高风险 |
| **<40分** | 较差 | 放弃操作，空仓观望 | 0 | 高风险 |

### 3.3 关键否决条件

**以下情况即使总分>70分也必须放弃操作**：

| 否决条件 | 说明 |
|---------|------|
| 环境分<10分 | 大盘趋势向下，系统性风险高 |
| 逻辑分<5分 | 纯题材炒作，无持续性 |
| 资金分<5分 | 北向+主力同时流出，信号失真 |
| 技术分<3分 | 关键支撑位跌破，趋势破坏 |
| 情绪分>13分 | 情绪亢奋期，加速赶顶风险 |

## 四、实战应用示例

### 4.1 工业富联（601138）案例

**背景**：2026年8月，AI服务器龙头

| 维度 | 得分 | 满分 | 得分依据 |
|------|------|------|---------|
| 环境 | 20/25 | 25 | 大盘周线多头，日均成交>2万亿，上涨家数65% |
| 板块 | 16/20 | 20 | AI主线清晰，成交额占比35%，板块有序轮动 |
| 逻辑 | 13/15 | 15 | 国家级政策支持，业绩增长>50%，超预期 |
| 情绪 | 10/15 | 15 | 连板高度5板，涨停80只，情绪上升期 |
| 资金 | 13/15 | 15 | 北向净流入3.2亿，主力大单净流入2.8% |
| 技术 | 8/10 | 10 | 倍量柱+大阳线，量价齐升，回踩黄金线不破 |
| **总分** | **80/100** | **100** | **优良级，积极参与** |

**决策**：
- 仓位：6成（对应70-84分等级）
- 买入价：71.5元（突破确认）
- 止损价：68.4元（黄金线）
- 目标价：78元（前高压力）
- 止盈：分批减仓（80元以上减半，90元以上清仓）

## 五、每日检查流程

### 5.1 盘前六维评分（9:00-9:25）

```
□ 环境维度（25分）
  - 查看昨日大盘涨跌家数
  - 检查周月均线状态
  - 统计日均成交额趋势
  
□ 板块维度（20分）
  - 筛选涨幅前5板块
  - 检查板块成交额占比
  - 判断主线是否清晰
  
□ 逻辑维度（15分）
  - 分析驱动因素（政策/业绩/消息）
  - 评估持续性
  - 对比市场预期差
  
□ 情绪维度（15分）
  - 统计连板高度
  - 统计涨停家数
  - 计算昨日涨停今日溢价
  
□ 资金维度（15分）
  - 查看北向资金流向
  - 检查主力资金净流入
  - 确认成交额配合情况
  
□ 技术维度（10分）
  - 识别倍量柱/黄金柱
  - 检查量价配合
  - 标注关键支撑压力位

□ 计算总分 → 制定操作计划
```

### 5.2 盘中动态调整（9:30-15:00）

- 每30分钟更新情绪维度得分
- 每2小时更新资金维度得分
- 突破关键价位时重新评估技术维度

### 5.3 盘后复盘（15:00-21:00）

- 计算当日六维得分
- 对比昨日预判准确率
- 记录失误案例
- 优化评分阈值

## 六、阈值优化建议

### 6.1 动态调整机制

| 市场状态 | 环境维度阈值调整 | 情绪维度阈值调整 |
|---------|----------------|----------------|
| 牛市初期 | 下调至18分合格 | 下调至8分入场 |
| 牛市中期 | 维持标准阈值 | 上调至12分警戒 |
| 牛市后期 | 上调至22分才入场 | 上调至14分离场 |
| 熊市初期 | 下调至15分就空仓 | 下调至6分离场 |
| 熊市中期 | 维持标准阈值 | 维持标准阈值 |
| 熊市后期 | 上调至20分才试探 | 上调至5分关注 |

### 6.2 个股差异化阈值

| 股票类型 | 技术维度阈值调整 | 资金维度阈值调整 |
|---------|----------------|----------------|
| 大盘蓝筹 | 技术权重+2分 | 资金权重+2分 |
| 中盘成长 | 维持标准阈值 | 维持标准阈值 |
| 小盘题材 | 技术权重-2分 | 资金权重-2分 |
| 科创板 | 技术权重-1分 | 资金权重+1分 |

## 七、总结

### 7.1 核心口诀

> 环境定去留，板块找主线；
> 逻辑判持续，情绪择时机；
> 资金验信号，技术选买点。
> 六维共振处，方是出手时。

### 7.2 关键阈值速记

| 维度 | 高确定性阈值 | 警戒阈值 | 放弃阈值 |
|------|------------|---------|---------|
| 环境 | ≥20分 | 15-19分 | <15分 |
| 板块 | ≥15分 | 10-14分 | <10分 |
| 逻辑 | ≥12分 | 8-11分 | <8分 |
| 情绪 | 9-11分入场 | 12-13分警戒 | >13分离场 |
| 资金 | ≥12分 | 8-11分 | <8分 |
| 技术 | ≥8分 | 5-7分 | <5分 |
| **总分** | **≥85分** | **70-84分** | **<70分** |
