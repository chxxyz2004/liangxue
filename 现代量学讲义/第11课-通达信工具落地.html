零、上节回顾（第二阶段开篇）

第一阶段10课，你学了量学的原理体系：位置百分位、黄金柱、十二字令、阴胜出、大盘三线、仓位联动。但这些都是"脑子里的概念"——你还没真正在通达信里看到过它们长什么样。

第二阶段的第①课就是来解决这件事：把工具装好，把眼睛练亮。以后你看到的每一根K线、每一根量柱，你都能知道它是干什么的。

一、前复权：你看到的价格才是真的

❌ 不复权的灾难：天孚通信案例

不复权 6月24日天孚收盘价显示约 480 元。

6月25日除权 价格跳到约 235 元，直接跌了50%+。

如果你看的是不复权数据，会以为天孚两天内腰斩——实际上只是除权跳空，股价走势是连续的。

👉 不复权的K线会出现"悬崖缺口"，生死线算错，黄金柱判断全废。

✅ 前复权的正确：平滑连续

前复权把历史价格按最新除权比例向下调整，K线图连续无缺口。

本课所有实战数据均基于前复权。

👉 前复权后，天孚6月24日价格约235元，6月25日231元——真实跌幅仅-1.7%，不是-50%。

1.1 通达信设置前复权（三步）

1
进入K线图

打开通达信 → 输入股票代码（如 300394 天孚通信）→ 按 Enter → 进入日K线图界面。

2
找到复权菜单

在K线图上 右键点击 → 弹出菜单中找到 "复权处理" 或 "前复权" → 点击。

手机端：点击K线图 → 底部菜单找 "设置" 或 "更多" → 找到 "复权方式" → 选择 "前复权"。

3
确认切换

切换后K线图应平滑无缺口。对比前后：不复权有断崖，前复权连续。这就是判断是否设对的唯一标准。

💡 记忆口诀："复权三不选：不复权、后复权、平均价，只选前复权。"

1.2 为什么是"前"复权而不是"后"复权？

复权方式逻辑适用场景本课使用
不复权显示实际成交价，保留除权缺口看历史真实交易价格❌ 不用
前复权用除权比例调整历史价格技术分析、走势判断✅ 只用这个
后复权用除权比例调整当前价格算投资收益❌ 不用

核心：技术分析看的是"相对走势"，不是"绝对价格"，所以前复权是唯一正确选择。

二、量比：判断成交活跃度的唯一量化指标

量比 = 当日每分钟平均成交量 ÷ 过去5日每分钟平均成交量

量比是"当下"的量能对比指标。1.0表示正常，大于1表示放量，小于1表示缩量。第8课学的"量比≥1.3"条件，就是用它来量化。

2.1 量比的分级标准

量比范围含义实战意义
< 0.5极度缩量抛压枯竭，也可能无人问津
0.5 - 0.8缩量回调阶段，等待确认
0.8 - 1.2正常观望为主
1.2 - 2.0温和放量 ✅最理想的入场区间（小倍阳）
2.0 - 3.0明显放量需警惕，可能是对倒出货
> 3.0异常放量 ⚠️高位放巨量=出货概率大

2.2 通达信查看量比（两种方式）

1
方式A：K线下方量柱图（推荐）

日K线图下方有量柱（彩色柱状图）。鼠标悬停在一根量柱上，会弹出信息框显示：量比=X.XX。

手机端：手指点击一根量柱 → 弹出详细信息卡片，找到 "量比" 一项。

2
方式B：技术指标栏添加量比指标

在K线图界面 → 底部找到 "指标" 或 "技术" → 搜索 "量比" → 选中 "VR(量比)" 或 "VOL" 指标。

添加后图表会显示量比曲线，方便持续观察。

💡 量比最佳区间：1.2-2.0。这是第8课"买入三问"中第二条"量比1.5-2.0"的直接来源。低于1.2不放量，高于2.0要警惕。

三、画线实操：四把尺子的通达信实现

画线是定"生死线"的核心手段，但画错了等于自欺欺人

第4课讲了"四把尺子"：箱体边沿、高量柱实顶、均线、缺口。通达信里每把尺子都有对应的画线方式。本课教你正确画和错误画的区别。

3.1 画线的三种工具

工具通达信路径适用场景
水平线工具 → 画线 → 水平线 / 快捷键 H箱体上下沿、整数关口、前高前低
趋势线工具 → 画线 → 趋势线 / 快捷键 T连接两个及以上低点/高点，画上升趋势/下降趋势
矩形工具 → 画线 → 矩形 / 快捷键 R箱体区间、震荡区间

3.2 正确画线：富联箱体案例

步骤分解

1
确定箱体区间

观察富联（300628）近3个月的K线走势，找到反复触及的最高价和最低价。

箱体上沿：约68.5元（多次触及回落）

箱体下沿：约62.0元（多次触及反弹）

2
画矩形/水平线

使用水平线工具，在68.5处画一条红线（压力线），在62.0处画一条绿线（支撑线）。

或者使用矩形工具一次性框住整个箱体。

3
验证有效性

回测：这两条线在过去的走势中是否多次被触及？每次触及后价格是否反弹/回落？

如果有效，这就是你的生死线。突破上沿=买点信号，跌破下沿=止损信号。

3.3 错误画线：常见陷阱

陷阱一：只画一个点就定线

错误做法：看到某个高点就画一条线，不管有没有其他点验证。

正确做法：至少两个点才能确定一条有效水平线。一个点只是"猜测"，两个点才是"验证"。

陷阱二：画线太多，互相矛盾

错误做法：箱体内画5条水平线，每条都说自己是"关键位"。

正确做法：取近取显一条够。最近的、被触碰最多的那条线才是真正的生死线。

陷阱三：用后复权数据画线

错误做法：不复权数据里有除权缺口，画出的"支撑线"其实是缺口造成的假象。

正确做法：必须先设前复权，再画线。本课所有画线操作均在复权模式下完成。

七、进阶提示：画线工具的高级用法

7.1 斐波那契回调线

通达信支持斐波那契回调线（工具 → 画线 → 斐波那契），用于预测回调目标位。常用回调位：23.6%、38.2%、50%、61.8%。

本课不强制使用，但你可以尝试在已知波段（如天孚6/24-6/25）上画一条，观察回调是否在这些位置止跌。

7.2 通道线

趋势线配合通道线可以画出"上升通道"或"下降通道"。通达信工具 → 画线 → 通道线，选择一个起点和终点自动生成通道。

实战用途：通道上轨=压力，通道下轨=支撑，价格在通道内运行。

7.3 画线管理

画多了线会乱。通达信支持画线管理：

  • 删除：选中画线 → 按 Delete 键
  • 隐藏：右键画线 → 隐藏/显示
  • 清空：工具 → 画线管理 → 清空所有画线
💡 画线纪律：每次只画1-2条最重要的线。线越多，信号越杂，决策越难。

八、本课核心要点

前复权 必须设前复权，不复权有缺口会毁掉所有技术分析。

量比 量比1.2-2.0是黄金买入区间；>2.0需叠加位置过滤。

画线 水平线至少两个点验证；取近取显一条够。

三位一体 前复权 + 画线 + 量比，三者结合才能得出可靠信号。

九、术语表（第11课新增）

术语通俗解释
前复权用除权比例调整历史价格，消除除权缺口，使K线连续。技术分析唯一正确选择。
不复权显示实际成交价，保留除权缺口。用于看历史真实价格，不适合技术分析。
后复权用除权比例调整当前价格。用于计算投资收益，不适合技术分析。
