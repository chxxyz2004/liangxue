第一单元：量线的基本原理
第1章 量线的定义与本质
1.1 什么是量线 核心概念

量线：以某一根关键量柱（将军柱、黄金柱等）为基准，通过特定规则画出的水平线或斜线。

量线的作用：标示支撑与压力，指导买卖操作。

核心思维：量线是量柱的延伸。找到正确的量柱，就找到了正确的量线。
1.2 量线的七大元素 核心框架
序号量线类型画法作用
1生死线箱体下沿（触碰≥2次）多空分界线
2进攻线将军柱实顶/跳空上沿买入信号
3防守线将军柱实底/跳空下沿止损信号
4精准线倍量柱右侧缩量确认验证信号
5灯塔线从王牌柱向左上倾斜目标指引
6合力线多根量线交汇点共振信号
7趋势线连接两个以上高点/低点趋势方向
第2章 生命线：防守线与进攻线
2.1 将军柱的画线原则 铁律

防守线（攻防线）的画法（从强到弱）：

  1. 将军柱后三日K线均在其实体上方 → 以实体上沿为防守线
  2. 有K线部分在下方 → 以实体下沿为防守线
  3. 所有K线都在下方 → 以三日最低点为防守线
  4. 跳空高开 → 以下方缺口上沿为防守线
关键：防守线一旦画出，跌破必须止损。这不是建议，是纪律。
2.2 进攻线的画法 买入信号

进攻线的画法：

  • ·普通将军柱：以将军柱实顶（收盘价）为进攻线
  • ·倍量将军柱：以倍量柱实顶为进攻线
  • ·跳空将军柱：以上方缺口上沿为进攻线
  • ·黄金柱：以黄金柱实顶为进攻线（更强信号）
买入时机：价格站稳进攻线上方 + 量能配合（缩量回踩或放量突破）→ 买入信号。
第3章 生死线：箱体的上沿与下沿
3.1 生死线的定义 关键防线

生死线：箱体运行的下沿线，是多空双方的"生命线"。

构成条件：

  • ·箱体下沿：价格至少两次触碰到同一水平位置
  • ·箱体上沿：价格至少两次触碰到同一水平位置
  • ·箱体颈线：箱体上沿与下沿的中线
3.2 生死线的实战意义 操作纪律
情况含义操作
站稳生死线多头强势持有或加仓
跌破生死线空头主导减仓或清仓
突破上沿启动信号追涨买入
回踩确认有效突破确认加仓
重要：生死的判定标准是"收盘价"还是"盘中价"？原著强调以收盘价为准，盘中破位不算。但实战中，急跌破位应提前应对。
第二单元：智能画线体系
第4章 精准线的画法与验证
4.1 精准线的定义 核心概念

精准线：以倍量柱或高量柱为基础，经过右侧缩量柱确认后画出的水平线。

构成条件：

  • ·左侧：倍量柱或高量柱（启动信号）
  • ·右侧：缩量柱（确认信号）
  • ·中间：价格回踩精准线后反弹
4.2 精准线的三类验证 确认方法
验证方式特征可信度
单线验证一根精准线被触碰一次中等
双线验证两根精准线交叉或平行较高
三线验证三根精准线形成共振最高
实战口诀：一验看形状，二验看位置，三验看力度。三线共振 = 最强信号。
第5章 灯塔线的画法与运用
5.1 灯塔线的定义 进阶概念

灯塔线：从王牌柱（将军柱/黄金柱）的最高点向左上方画出的斜线，用于预测反弹目标位。

画法：

  1. 找到将军柱或黄金柱的最高点
  2. 从左向右画一条斜线（约45度角）
  3. 后续价格触及此线 = 目标位到达
5.2 灯塔线的实战应用 目标预判
  • ·向上灯塔线：预测上涨目标位，到达后考虑减仓
  • ·向下灯塔线：预测下跌目标位，到达后考虑抄底
  • ·灯塔线+精准线：双重确认，信号更强
第6章 合力线与共振信号
6.1 合力线的定义 高级概念

合力线：多条量线（生死线、进攻线、精准线等）交汇于同一位置，形成共振效应。

合力线形成条件
≥2条线交汇于同价位
信号强度
交汇线越多越强
6.2 共振信号的分级 信号强度
级别交汇线数量信号强度操作建议
一级共振2条较强重点关注
二级共振3条很强果断操作
三级共振≥4条极强重仓出击
第三单元：量线实战技法
第7章 黄金柱画线三步法
7.1 画线第一步：找王牌柱 定位

找到将军柱后，进一步确认是否为黄金柱：

  1. 确认将军柱：后三日不破其实底
  2. 确认黄金柱：后三日缩量且收盘价不破实顶
  3. 标记位置：在K线图上标注黄金柱编号
7.2 画线第二步：画防守线 关键

以黄金柱为基准，按优先级画防守线：

情况防守线位置强度
三日K线均在实顶上方实顶（收盘价）最强
部分K线在下方实底（最低价）中等
全部K线在下方三日最低点最弱
跳空高开缺口上沿较强
7.3 画线第三步：画进攻线 买入信号

进攻线的位置决定买入时机：

  • ·进攻线在实顶：价格回到实顶附近 = 买入机会
  • ·进攻线在实底：价格回到实底附近 = 加仓机会
  • ·进攻线与防守线重合：该价位既是支撑也是压力
买入策略：进攻线附近低吸 + 防守线设止损 = 最佳买卖组合。
第8章 精准线画线四步法
8.1 精准线画线步骤 操作技法
  1. 找倍量柱：左侧找到倍量柱（启动信号）
  2. 画水平线：以倍量柱的实顶或实底为基准画水平线
  3. 右侧确认：观察右侧是否有缩量柱回踩此线后反弹
  4. 验证强度：触碰次数越多，线的有效性越高
8.2 精准线的三类形态 形态识别
V形确认
回踩后V型反弹
W形确认
两次回踩确认
平底确认
多次回踩不破
假突破确认
突破后快速收回

10.2 量线操作铁律 铁律
  • ·不破不立：守住防守线才能持有，跌破防守线必须走
  • ·量价同步：突破量线时必须有量能配合
  • ·共振优先：共振位优先于单一信号
  • ·左证右验：左边有依据，右边有确认才动手
  • ·宁错过不做错：信号不明确时，观望胜过操作
10.3 量线与量柱的配合使用 综合技法
最佳组合：
量柱找王牌柱 → 量线画防守线/进攻线 → 量性确认信号 → 量级判断强度

例如：
① 找到倍量柱（启动信号）
② 三日不破 → 确认为将军柱
③ 画出生死线（防守线）
④ 回踩生死线缩量 → 加仓信号
⑤ 突破进攻线放量 → 加仓确认
