第5课 · 进阶关键位与确认——逐天拆解

现代量学实战体系 · 针对"右确认要等几天"的追问 · 授课：黑马王子（张得一）
全部数据来源：本地行情数据库（新浪财经官方日K接口），逐日核验含量比/涨跌幅计算

一、先解开"悖论"：右确认不是无限循环

你的疑问："如果每天都是左、每天又要等右，那岂不是永远在等？"

答案：右确认不是"每天都重新等一次"，而是"一个信号，配一条生死线，盯着它直到分出胜负"。

左信号出来后，它自带一条关键位（生死线）。之后每一天，不是"重新确认"，而是反复核对同一个问题：价格站上关键位了吗？还是跌破了？

  • 站上关键位 → 右确认 → 进场；
  • 跌破关键位 → 右证伪 → 放弃；
  • 没上没下 → 继续等（此时空仓等待本身就是正确答案，不是"没确认"）。

所以不是"每天都要新的右"，而是"一个左、一个关键位，盯着它直到站上或跌破"。逻辑闭合，不发散。

回答："8/21价涨量涨，为什么不是进场点？"

你看到：8/20地量（✓左信号）+ 8/21价涨量涨，逻辑没错，但漏了第四步——看关键位：

  1. 8/20地量是"左"（抛压减轻）——✓你说对了；
  2. 8/21价涨量涨（量比1.02）看似确认——但它最高63.38、收62.84，连8/19破位前的箱体下沿64.51都没站回去；
  3. 8/20-21在61.5-63.4小平台缩着，关键位64.51在头顶压着。

正确读法：8/21不是"确认日"，而是"仍在观察期"。真正的右确认要等放量收回64.51上方；而它等来的却是8/24放量跌破61.5——右证伪。

你漏的这一步，就是"左证明右确认"和"看到反弹就买"的区别。地量企稳只是"跌不动了"，不叫"要涨了"；跌不动→站回关键位→才叫确认。

回答："8/18明明确认了，8/19又证伪，岂不是没完没了？"

右确认分级别，每一级都配一条止损线。

  • 8/18的确认，确认的是"8/17启动有效"——它成立了（量价齐升）；
  • 但8/18同时给出新的"左"：它冲高72.56，突破后能否守住？
  • 8/19的缩量跌停，跌破的就是8/18确认的根基（若8/18是有效启动，就不该一天跌回原位）。

所以不是"确认被推翻"，而是每一个确认都自带一条生命线：8/18确认有效→生命线是8/17低点/8/18收盘；8/19跌破生命线→确认作废、走人。你不会"无限等待"，因为生命线给了你明确的"判死刑"标准。

四、回答"观察几天"——标准答案

右确认不看天数，看关键位。

左信号出现后，把关键位划出来（前高、前低、箱体边沿、均线）。之后每天只核对一件事：站上=确认（进），跌破=证伪（弃），横着=继续等（不动）。

天数可以是1天、3天、10天，决定权在价格，不在日历。"观察几天"不是悖论，因为每一天看的都是同一个问题、同一条线。你不需要"确认昨天的确认"，只需要盯住那条线：价格和线的相对关系，每天只有三种可能（上/下/横），不会发散。

五、一句话总结（请记到笔记里）

左信号 = 抛个问题；关键位 = 裁判；右确认 = 价格和裁判的关系。

站上裁判线 → 进场；跌破裁判线 → 离场；没站上也没跌破 → 空仓等待本身就是正确答案。
