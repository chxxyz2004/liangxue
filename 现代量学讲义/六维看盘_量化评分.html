六维看盘量化评分体系

核心原则：总分100分，各维度权重不同，设置明确阈值

一、六维权重分配（总分100分）

维度权重等级核心作用
环境维度25分一票否决决定去留、仓位、策略选择
板块维度20分关键筛选决定主线热点、资金流向
逻辑维度15分持续性决定行情持续时间
情绪维度15分入场时机决定买点在哪个情绪阶段
资金维度15分信号验证决定技术信号是否可信
技术维度10分择时买点决定具体入场价位和止损位

二、各维度详细评分标准

2.1 环境维度（25分）⭐ 最高权重

核心问题：现在是增量牛还是缩量熊？

评分项满分得分标准阈值
大盘趋势方向8分周月均线多头排列且向上>20日均线=+4分，均线拐头向上=+4分
成交量趋势8分日均成交额>2万亿且放量>2.5万亿=+5分，>2万亿=+3分，<1万亿=-4分
市场宽度9分上涨家数占比>60%=+4分，<40%=-2分
一票否决条件（直接判定"放弃操作"）：
- 大盘周月均线双死叉 + 成交量连续5日萎缩 → 总分<10分，强制空仓
- 上证指数跌破20周均线且放量下跌 → 总分<15分，减仓至2成以下

2.2 板块维度（20分）

评分项满分得分标准阈值
主线清晰度7分是否有明确主线板块主线清晰=+7分，无主线=-3分
板块轮动节奏6分板块轮动是否有序有序轮动=+6分，无序轮动=-3分
资金集中度7分成交额占比前10%个股吸走多少资金>50%=+7分，<30%=-2分

2.3 逻辑维度（15分）

评分项满分得分标准阈值
驱动类型5分政策/业绩/消息政策驱动=+5分，消息驱动=+2分
持续性判断5分长期成长还是短期炒作产业周期3年以上=+5分，<1年=+1分
预期差5分市场预期vs实际情况超预期=+5分，低于预期=-3分

2.4 情绪维度（15分）

评分项满分得分标准阈值
连板高度5分市场最高连板数≥7板=+5分，<3板=-2分
涨停家数5分当日涨停股票数量≥100只=+5分，<20只=-3分
赚钱效应5分昨日涨停今日溢价平均涨>3%=+5分，<0%=-3分
情绪阈值：
- 情绪亢奋线：主板涨幅>3% + 创业板涨幅>5% → 阶段性顶部预警
- 情绪冰底线：跌停家数>50只 + 连板高度<3板 → 底部信号关注

2.5 资金维度（15分）

评分项满分得分标准阈值
北向资金5分北向资金净流入>50亿=+5分，<0=-3分
主力资金5分大单净流入占比>3%=+5分，<0=-3分
成交额验证5分高价股成交额是否同步放大同步放大=+5分，背离=-3分

2.6 技术维度（10分）

评分项满分得分标准阈值
K线形态4分主力行为信号倍量柱+阳线=+4分，普通阳线=+1分
量价配合3分量价关系健康度量价齐升=+3分，量价背离=-2分
支撑压力3分关键价位确认回踩支撑不破=+3分，破位=-3分

三、六维共振决策模型

3.1 总分计算

总分 = 环境分 + 板块分 + 逻辑分 + 情绪分 + 资金分 + 技术分 最高分：100分 最低分：-40分（各维度最低分之和）

3.2 决策阈值表

总分区间等级操作建议仓位上限风险等级
85-100分极优果断出击，抓住主升浪8成低风险
70-84分优良积极参与，顺势而为6成中低风险
55-69分一般选择性参与，控制仓位4成中风险
40-54分偏弱轻仓试探，设紧止损2成中高风险
<40分较差放弃操作，空仓观望0高风险

3.3 关键否决条件

以下情况即使总分>70分也必须放弃操作：
  • 环境分<10分：大盘趋势向下，系统性风险高
  • 逻辑分<5分：纯题材炒作，无持续性
  • 资金分<5分：北向+主力同时流出，信号失真
  • 技术分<3分：关键支撑位跌破，趋势破坏
  • 情绪分>13分：情绪亢奋期，加速赶顶风险

四、核心口诀

环境定去留，板块找主线；
逻辑判持续，情绪择时机；
资金验信号，技术选买点。
六维共振处，方是出手时。
