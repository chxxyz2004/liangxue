# 量线捉涨停 系统讲义

# 上篇：理论基础

## 第1讲 量线理论概述

### 一、量线概念的提出

**量线定义：**
量线是由关键量柱生长出来的水平线或斜线，是对股价运行轨迹的真实刻画。与传统的阻力线、支撑线不同，量线是由量柱决定的，具有更强的科学性和实战价值。

**量线的核心定义：**
由关键量柱生长出来的才是量线。这是黑马王子对量线概念的重要界定，标志着量线理论从传统技术分析中的"画线派"中脱颖而出。

### 二、量线与传统的区别

传统技术分析中的"线"：
- 趋势线：连接高低点，主观性强
- 支撑线/阻力线：基于心理价位，缺乏量柱依据
- x线：单一的阻力线，不具备连续观察功能

量线理论的创新：
- 以量柱为基础，有明确的生成依据
- 平衡线与平衡线的交叉互动，可精准刻画任何一只股票的长期走势
- 不仅对股价的当下有影响，还会影响到股价将来的控制势

### 三、量线的核心意义

**量线是股价运动规律的外在表现：**
股价从某一点A运行到某一点B，中间处于一种随机状态，会有很多莫名其妙的起伏。但A点、B点的形成并不是随意的，某些位置是它们出现的大概率位置。

**量线的三大功能：**
1. **支撑功能**：量线是多头的防线，股价回踩不破是买入信号
2. **压力功能**：量线是空头的防线，股价反弹不过是卖出信号
3. **预测功能**：通过量线的交叉互动，可以预测股价未来的运动轨迹

## 第2讲 量线的四大定律

### 第一定律：凡是涨停板，必是人为的

**核心含义：**
任何一只股票的涨停板都不是天上掉下来的，也不是地里冒出来的，是股市里炒作的人炒作起来的。有人为的炒作，才有股票的涨停。

**实战意义：**
- 涨停板是主力行为的结果
- 研究涨停板就是研究主力的行为
- 只要是人做的，就必然有人的踪迹

### 第二定律：凡是人为的，必然有踪迹

**核心含义：**
只要是人为的事，必然会留下人的踪迹；根据留下的痕迹，一定可以找到他的作案方法和手段。从这个意义上讲，**伏击涨停就等于警察抓小偷**。

**实战意义：**
- 沿着人的踪迹，一定能找到他的方法和手段
- 这就是"伏击涨停"的核心思想
- 通过量柱和量线的变化，可以追踪主力的行为轨迹

### 第三定律：凡有踪迹，必然有规律

**核心含义：**
中国有句古话："无风不起浪。"凡是有踪迹的地方，一定有规律可循。涨停板的形成有其内在的规律，这些规律体现在量柱的变化和量线的交错中。

**实战意义：**
- 通过量柱的形态变化，可以识别涨停的前兆
- 通过量线的支撑压力关系，可以判断涨停的可能性
- 掌握了规律，就能提前预判涨停

### 第四定律：凡有规律，必然可复制

**核心含义：**
现代科学告诉我们，可以复制的技术，才是科学的技术；可以推广的技术，才是成熟的技术。伏击涨停的方法和技巧，是可以学习和掌握的。

**实战意义：**
- 不是天才才能学会，普通人通过系统学习也能掌握
- 关键在于理解和运用，而不在于天赋
- 通过大量案例的验证和练习，可以提高准确率

## 第3讲 攻防十字经——十二字令

### 一、最基本的"两种柱"

**量柱和价柱：**
伏击涨停的基础是"量柱"和"价柱"。

**量柱的四种基本形态：**
1. **倍量柱**：比前一日量柱高出一倍左右的量柱
2. **高量柱**：某一阶段的最高量柱
3. **缩量柱**：比前一日量柱逐步缩小的量柱
4. **平量柱**：与前一日量柱持平的量柱

**价柱的阴阳之分：**
- 阳柱（红柱）：收盘价高于开盘价
- 阴柱（绿柱）：收盘价低于开盘价

### 二、最核心的"十二字令"

**十二字令：**
> 阳胜进，阴胜出；小倍阳，大胆入。

**含义解析：**

**第一层：从量柱上看**
- 红柱高过是阳胜，阳胜则进
- 绿柱高过是阴胜，阴胜就出
- 这里的"胜"是"胜利的胜"，不是"花费的胜"

**第二层：从价柱上看**
- 只要今天红柱的实体高于昨天阴柱的实体，就是"阳胜"
- 只要今天绿柱的实体低于昨天红柱的实体，就是"阴胜"
- 价柱的胜一定要看实体，量柱的"实体实底"是胜的临界点

**第三层：从组合上看**
- "量价同胜"是"胜"的重要标志
- 今天的量柱和价柱同时高过昨天的量柱和价柱，即"双向胜"才是"阳胜"
- 反之，如果今天的量柱和价柱同时"双向胜阳"，才是"阴胜"

**第四层：从量价比看**
- "阳胜"或"阴胜"特指"双向胜"
- 如果遇到"单向胜"的状况，最好还是"看一样"，即观望
- 发现"长阴短柱"或"长阳短柱"要具体情况具体分析

**第五层：从倍量上看**
- 只要今天的量柱比昨天的量柱高出一倍左右（ not 高出许多），阳柱就是"小倍阳"，阴柱就是"小倍阴"
- 若高出一倍以上，就是"大倍阳"或"倍阳"
- 若高出五倍以上，那就是"五倍阳"或"七倍阳"

### 三、最狡猾的"阴阳柱"

**什么是阴阳柱：**
在走势图上有些量柱看起来是"阴的"，实质上是"阳的"，如高开低走的阴柱就是假阴；有时看起来是"阳的"，实质上是"阴的"，即低开高走的阳柱就是假阳。

**特别警惕：**
特别是"临界点"附近出现的这种"阴阳柱"，往往是骗人的重要量柱。

**实战要点：**
- 不要只看表面的红绿颜色
- 要结合量柱的实质高度和位置来判断
- 假阴真阳往往是主力吸筹的信号
- 假阳真阴往往是主力出货的信号

## 第4讲 量柱七因子

### 一、量柱七因子的定义

**什么是量柱七因子：**
在某个阶段里高出的柱子，就是高量柱；凡是与左侧量柱高度基本相等的，就是平量柱；凡是比左侧量柱高出一倍左右的，就是倍量柱；凡是比左侧量柱逐步升高的柱子，就是梯量柱；凡是比左侧量柱逐步降低的柱子，就是缩量柱；凡是某一阶段的最低量柱，就是低量柱；凡是与左侧量柱高度基本相等的，就是平量柱。

**七因子总结：**
| 因子 | 定义 | 特征 |
|------|------|------|
| 高量柱 | 某一阶段最高量柱 | 可能是天量，也可能不是 |
| 低量柱 | 某一阶段最低量柱 | 可能是地量，也可能不是 |
| 倍量柱 | 比前一日高出一倍左右 | 实力介入的标志 |
| 平量柱 | 与前一日基本持平 | 蓄势信号 |
| 梯量柱 | 比前一日逐步升高 | 逐步增仓 |
| 缩量柱 | 比前一日逐步缩小 | 价升量缩最有价值 |
| 将军柱 | 能独当一面的支撑柱 | 关键支撑位 |

### 二、量柱七因子的组合

**七因子的组合形成涨停基因：**
一定的因子可以组合成丰富多彩的涨停基因；一定的涨停基因按一定的规律排列组合，又可组成丰富多彩的涨停密码。

**经典组合：**
- 倍量柱 + 缩量柱 = 黄金柱
- 低量柱 + 倍量柱 = 黄金柱
- 梯量柱 + 倍量柱 = 黄金柱
- 高量柱 + 缩量柱 = 高量黄金柱

## 第5讲 股市三规律

### 一、量柱的三大特性

1. **真实性**：有成交才有记录，不会因为有人在K线或均线上做假而改变其形态
2. **有效性**：成交多，柱体就高；成交少，柱体就矮，不因人为操控而影响高矮
3. **敏感性**：暂时平衡中蕴藏着新的倾斜，蕴含着新的挑战和机遇

### 二、神奇的股市密码

**操盘密钥：**
所谓"操盘密钥"，就是比"十二字令"更巧妙的买卖信号。

**核心法则：**
- 凡是倍量柱后面三天出现价升量缩，就是黄金柱
- 黄金柱是主力的成本线，跌破意味着主力放弃
- 守住黄金柱意味着行情延续

### 三、三先规律的运用

**三先规律：**
1. 卖在买先——卖买平衡律
2. 价在量先——价量平衡律
3. 庄在散先——庄家导向律

**运用方法：**
用"三先规律"来检验庄家、衡量主力，一根量柱就能看出主力的意图和动向。

## 第6讲 眼光——股市探宝仪

### 一、眼光的"透视性"

**核心观点：**
眼光是所有行为的起点，也是伏击涨停的起点。不同的眼光决定伏击涨停的成功与失败。

**透视性含义：**
透过量柱的表象，看到主力的本质意图。不是看K线的颜色，而是看量柱背后的力量对比。

### 二、眼光的"折射性"

**核心观点：**
同样的量柱，在不同位置、不同背景下，有不同的含义。需要通过多角度分析来验证。

### 三、眼光的"继承性"

**核心观点：**
量柱理论是建立在传统技术分析基础上的继承和发展。不是推翻，而是升华。

### 四、眼光的"自闭性"

**核心观点：**
有些人犯了"自闭性"错误，看不到已有的信号，总以为还有往下抄底的可能。要避免这种思维定式。

## 第7讲 眼力——股市探宝机

### 一、静态分析法

**核心方法：**
用"左推法就近比较"，提取的各种形态才好辨认。

**分析方法：**
- 找出重要量柱：A是倍量柱，B是高量柱，D是低量柱，E是平量柱

- 判断量柱的性质和级别

**核心方法：**
活力就是动力，动力暗示动向，动向必有动静。

**分析方法：**
- 观察量柱的动态变化
- 分析价量关系的演变
- 判断主力的动向和意图

### 三、规律分析法

**核心方法：**
用规律来分析量柱，可以更准确地判断走势。

# 中篇：核心战法

## 第8讲 王牌——涨停起搏器

### 一、将军柱的三个标准

**第一个标准：看量柱。**
将军柱是独当一面的柱子，必须是一柱定音。

**第二个标准：看价柱。**
基柱后三日的收盘价不低于基柱的开盘价。
不破实底就是：基柱后三日的收盘价没有跌到基柱的开盘价。

**第三个标准：看量柱群。**
基柱后三日的量柱都不超过基柱。

### 二、黄金柱的三个标准

**标准一：**
必须是某一阶段的"将军柱"。

**标准二：**
其后三天必须价升量缩。

**标准三：**
三天内不能跌破黄金柱的最低价位。

### 三、黄金柱与将军柱的区别

- 将军柱是能独当一面的支撑柱
- 黄金柱是将军柱的升华版本
- 黄金柱比将军柱更有价值，是市场动能的焦点

### 四、黄金柱的预判技巧

**预判原则：**
- 先找倍量柱
- 再看后三天的量价关系
- 确认价升量缩后，判定为黄金柱
- 黄金柱形成后，在回踩时介入

### 五、研判中的两个原则

**原则一：先者优先**
当多个黄金柱在一起时，以最先形成的为准。

**原则二：空补空**
如果有多个黄金柱，后面的黄金柱可以补充前面的不足。

### 六、元帅柱的三个标准

**核心特征：**
隐藏在标准黄金柱左侧的不显眼的基准黄金柱，称之为"隐形黄金柱"。凡是有"隐形黄金柱"的，后面的走势往往更加强劲。

## 第9讲 跳板——金线战法要点

### 一、金线战法的画线（逆势画线）

**什么是金线：**
所谓"金线"，就是"黄金线"的简称，它是主庄苦心经营的"攻防线"，又是主庄操盘计划的体现。

**黄金线的取点方法：**
- 以黄金柱的最高价为基准
- 向左画水平线
- 至少要经过三个趋势点才能定位
- 线越直、越长，支撑力越强

**黄金线的分类：**
1. **黄金线**：以黄金柱的最高价为基准画出
2. **元帅线**：以元帅柱的最高价为基准画出
3. **将军线**：以将军柱的最高价为基准画出

**可靠性排序：**
元帅线最可靠，黄金线较可靠，将军线不太可靠。

### 二、对付强庄的画法（强庄踩顶）

**核心战法：**
对付强庄的"金线战法"，就是以黄金柱所对应的价柱实顶画出金线，用测算涨幅来确认主力的攻防路线。

**实战要点：**
- 强庄股的黄金线往往比较明显
- 主力会依托黄金线进行拉升
- 回踩黄金线是最佳介入点

### 三、对付狡庄的画法（狡庄踩脚）

**核心战法：**
对付狡庄的"金线战法"，就是以黄金柱（或将军柱）后一日价柱的最低实底和虚底画出虚实两条金线，用测算或确认主庄的攻防路线。

**实战要点：**
- 狡庄股的黄金线往往虚实相间
- 在虚实相间的两条金线之间可设立伏击圈
- 虚线是假支撑，实线是真支撑

### 四、金线战法的核心：跟着主力走

**核心原则：**
金线战法的精髓是跟着主力走。主力的动作是有规律的，通过金线可以追踪主力的行踪。

### 五、金线战法的灵魂：用活黄金柱

**灵活运用：**
- 黄金柱不是固定不变的
- 同一根量柱在不同位置有不同的含义
- 要根据具体情况灵活判断

## 第11讲 骨架——"黄金双线"画法

### 一、"黄金双线"的基本原理

**什么是黄金双线：**
在同一根黄金柱上，画出两条黄金线：一条以实顶为基准，一条以实底为基准。两条线形成"双线"结构。

**核心意义：**
- 实顶线是进攻线
- 实底线是防守线
- 双线之间是主力的成本区

### 二、"黄金双线"的买卖决策

**买入信号：**
- 股价回踩实底线企稳
- 倍量柱确认支撑有效
- 量价配合良好

**卖出信号：**
- 股价跌破实底线
- 量柱异常放大
- 主力出货迹象

### 三、"黄金双线"的灵活应用

**实战要点：**
- 双线结构越清晰，信号越可靠
- 要结合其他量柱形态综合判断
- 注意双线的角度和长度

## 第12讲 抗线——"黄金十字"画法

### 一、什么是"黄金十字"

**定义：**
"黄金十字"是由黄金线和另一条重要量线交叉形成的十字形态。

**形成条件：**
- 一条水平黄金线
- 一条斜向的趋势线
- 两条线形成交叉

### 二、如何寻找"黄金十字"

**寻找方法：**
1. 找出黄金柱和对应的黄金线
2. 画出趋势线（连接重要高低点）
3. 观察交叉点的位置
4. 交叉点往往是重要的买卖信号

### 三、如何使用"黄金十字"

**使用原则：**
- 交叉点上方的黄金线是压力
- 交叉点下方的黄金线是支撑
- 突破交叉点是买入信号
- 跌破交叉点是卖出信号

### 四、如何纠正"黄金十字"

**纠错要点：**
- 不是所有的交叉都是有效的
- 要验证交叉点后的走势
- 不符合预期的交叉要重新审视

### 五、实战验证"黄金十字"

**验证方法：**
- 用历史案例验证交叉点的有效性
- 统计交叉点后的走势概率
- 在实践中不断提高判断能力

## 第13讲 标尺——大阴实攻线法

### 一、"阴胜战法"的原理

**核心概念：**
"阴胜"是指绿柱高过红柱，意味着空方力量占优。但"阴胜"有真假之分，需要仔细辨别。

**实战意义：**
- 真阴胜是卖出信号
- 假阴胜是买入机会
- 关键在于辨别真假

### 二、"大阴实攻"的画法

**画法要点：**
- 以大阴柱的实底为基准
- 向左画水平线
- 这条线是多头的最后防线

**实战应用：**
- 股价回踩大阴线企稳是买入机会
- 跌破大阴线是止损信号
- 大阴线是重要的支撑位

### 三、"大阴中阳"的画法

**画法要点：**
- 以大阴柱中的阳柱实顶为基准
- 画出支撑线
- 这条线比大阴线更强

**实战应用：**
- 中阳线是大阴中的亮点
- 突破中阳线是强势信号
- 回踩中阳线是介入良机

### 四、"阴胜战法"的要点

**要点总结：**
1. 先辨别阴阳柱的真假
2. 再确定支撑线的位置
3. 最后选择介入时机
4. 设置好止损位

## 第14讲 暗号——阴胜柱战法

### 一、"长阴短柱"的基本玩法

**定义：**
"长阴短柱"是指一根长长的阴线，但对应的量柱却很短。

**市场含义：**
- 股价大跌但量能萎缩
- 说明抛压不重
- 往往是主力洗盘的信号

**实战玩法：**
- 在长阴短柱的次日介入
- 止损位设在长阴的最低点
- 目标位看前一个平台的顶部

### 二、"假阴真阳"的识别技巧

**识别方法：**
- 高开低走的阴柱，实体很小
- 对应的量柱也很短
- 实际上是主力在吸筹

**实战应用：**
- 假阴真阳是买入信号
- 要等次日确认后再介入
- 配合黄金柱使用效果更佳

### 三、经典战法解析

**案例一：**
某股票出现长阴短柱，次日放量上涨，突破长阴的最高点，确认是主力洗盘后的拉升。

**案例二：**
某股票出现假阴真阳，量柱极短，后续连续小阳线推升，形成黄金柱后大涨。

## 第15讲 抓手——一剑封喉战法

### 一、"一剑封喉"的机理

**核心概念：**
"一剑封喉"是指在关键位置出现一根倍量柱，一举突破前期平台，形成涨停或大涨。

**形成条件：**
1. 前期有充分蓄势（平台整理）
2. 出现倍量柱突破
3. 突破后不回踩或回踩不破

### 二、"一剑封喉"的表法

**表法要点：**
- 倍量柱是信号柱
- 突破位是介入点
- 止损位设在倍量柱的最低点

**实战操作：**
- 在倍量柱当天尾盘介入
- 或次日回踩时介入
- 严格止损，不可犹豫

### 三、"一剑封喉"的凹口诀

**凹口诀：**
"凹口淘金"是"一剑封喉"的前置条件。在凹口位置出现倍量柱，是最佳的介入时机。

### 四、"一剑封喉"的满盘诀

**满盘诀：**
当"一剑封喉"形成后，后续往往有一波可观的涨幅。要持有到出现卖出信号为止。

## 第16讲 先兆——倍量伸缩战法

### 一、"倍量伸缩"的基本特征

**定义：**
"倍量伸缩"是指倍量柱和缩量柱交替出现的形态。

**特征：**
- 倍量柱后出现缩量柱
- 缩量柱后再次倍量柱
- 形成"伸缩"节奏

**市场含义：**
- 倍量柱是主力建仓或拉升
- 缩量柱是主力洗盘或蓄势
- 伸缩交替说明主力在控制节奏

### 二、"倍量伸缩"的伏击位置

**伏击点：**
- 倍量柱当天的尾盘
- 缩量柱后的倍量柱形成时
- 回踩黄金线企稳时

### 三、"倍量伸缩"的涨停契机

**契机判断：**
- 倍量柱后缩量三日
- 缩量柱低于倍量柱的一半
- 再次出现倍量柱时是涨停契机

### 四、"倍量伸缩"的启动迹象

**启动信号：**
- 倍量柱突破前期平台
- 量能配合良好
- 价柱稳步推升

### 五、"倍量伸缩"的位量论证

**论证方法：**
- 分析倍量柱的位置（低位还是高位）
- 论证缩量的程度（是否是有效缩量）
- 确认后续倍量柱的力度

## 第17讲 契机——现场直播法

### 一、"现场直播"的基本特征

**核心概念：**
"现场直播"是指在盘中实时观察量柱和价柱的变化，即时做出买卖决策。

**特征：**
- 需要快速反应能力
- 需要对量柱理论有深刻理解

### 二、"现场直播"的市场机制

**机制解析：**
- 盘中量柱的变化反映主力的即时行为
- 价柱的变化反映市场的即时反应
- 两者结合可以判断当天的走势

### 三、"现场直播"的介入时机

**时机选择：**
- 开盘后30分钟的量柱变化
- 午盘前的关键量柱形成
- 尾盘最后的量柱确认

# 附录：核心公式汇总

## 一、黄金线测幅公式

```
第一目标位 = 黄金柱最低价 × 2
第二目标位 = 黄金柱最低价 × 2.5
实际涨幅 = (目标位 - 介入价) / 介入价 × 100%
```

## 二、金线战法买入公式

```
买入点 = 黄金线回踩企稳 + 倍量柱确认
止损点 = 黄金线下方 3%
目标位 = 前高或测算涨幅
```

## 三、十二字令判定公式

```
阳胜 = 量柱双向胜 + 价柱实体胜
阴胜 = 量柱双向负 + 价柱实体负
小倍阳 = 量柱高出一倍左右 + 价柱上涨
大胆入 = 确认阳胜后介入
```

## 四、将军柱判定公式

```
将军柱 = 倍量柱或高量柱 + 后三日价不破实底 + 量柱群不超过
```

## 五、黄金柱判定公式

```
黄金柱 = 将军柱 + 后三日价升量缩 + 三日不破实底
```
