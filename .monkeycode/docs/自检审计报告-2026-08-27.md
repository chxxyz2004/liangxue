## 二、发现的BUG及修复

### BUG-001: 对倒检测脚本退出码错误
- **问题**: detect_spoofing.py使用`sys.exit(main())`，当检测到95个异常信号时返回exit code 95，导致auto_update.sh误判为失败
- **影响**: 每日自动更新日志显示"对倒检测失败"
- **修复**: 改为`main()`直接调用，成功返回0
- **状态**: ✓ 已修复

### BUG-002: 8086端口Content-Type配置错误
- **问题**: server.py静态文件处理器未指定charset，部分浏览器可能将HTML当文件下载
- **影响**: 用户访问8086端口可能触发下载行为
- **修复**: Content-Type改为`text/html; charset=utf-8`
- **状态**: ✓ 已修复

### BUG-003: HOLDINGS配置重复定义
- **问题**: 7个文件各自定义了HOLDINGS字典，维护困难易出错
- **影响**: 修改持仓需同步修改多处代码
- **修复**: 创建统一配置文件`config.py`，所有文件引用同一数据源
- **状态**: ✓ 已修复
