## 三、回测执行计划

### 优先级排序（按实战使用频率）

1. **第一优先**：倍量柱买入（基础战法，使用频率最高）
2. **第二优先**：左证明右确认（核心战法，所有买点必须经过此验证）
3. **第三优先**：生死线突破（辅助战法，配合前两者使用）
4. **第四优先**：缩量回调支撑（低风险买点）
5. **第五优先**：凹口淘金（差异化竞争点）

### 回测执行步骤

```
步骤1：编写回测策略
  - 明确买入条件（如：倍量柱+阳胜+位置<70%+量比1.3-2.0）
  - 明确止损条件（如：跌破倍量柱最低点-2%）
  - 明确止盈条件（如：涨幅≥10%或跌破5日线）

步骤2：本地数据回测
  - 使用/python3 /workspace/行情数据库/backtest.py 策略名
  - 输出：胜率、盈亏比、最大回撤、样本量

步骤3：结果评估
  - 胜率≥50%且盈亏比≥1.5:1 → 标记"有效"，纳入教学
  - 胜率<45%或盈亏比<1.5:1 → 标记"待验证失效"，暂停教学
  - 样本量<30 → 标记"样本不足"，继续积累

步骤4：迭代优化
  - 失效战法需添加过滤条件（如：加入大盘环境判断）
  - 重新回测直到达标
```

## 六、回测纪律

1. **每学完1个战法，30天内完成回测**，不得拖延
2. **回测数据必须可核实**，禁止凭记忆下结论
3. **失效战法立即暂停教学**，标记"待验证失效"并给出替代方案
4. **每次实战后更新回测记录**，累计样本量
5. **回测达标后纳入教学**，未达标不得使用于实战建议
